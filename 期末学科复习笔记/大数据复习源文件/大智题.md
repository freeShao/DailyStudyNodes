## 4. 简答题

### 4.1. 请简述MapReduce工作流程的各个阶段及其主要功能。
>
**答案：**
**① Split（分片）阶段**：将输入数据逻辑切分成多个分片，**每个分片对应一个Map任务**。
**② Map（映射）阶段**：解析每个分片中的数据，**输出中间键值对**。
**③ Shuffle（洗牌）阶段**：这是一个**自动执行**的中间过程，负责将Map输出的键值对按Key进行**分区、排序和分组**，然后传输给对应的Reduce任务。
**④ Reduce（归约）阶段**：接收Shuffle后的数据，对相同Key的Value集合执行用户定义的聚合逻辑（如求和、求平均）。
**⑤ 输出阶段**：将Reduce结果写入HDFS指定输出目录。
### 4.2. HDFS集群启动之后会有哪三个进程，它们的作用分别是什么。
>
**答案：**
**NameNode**：管理文件系统**命名空间**，存储**元数据**（文件目录树、块位置映射等），协调客户端访问。
**DataNode**：负责存储实际**数据块**，执行数据读写操作，并定期向NameNode发送心跳及块报告。
**SecondaryNameNode**：辅助NameNode合并**编辑日志和镜像文件**，定期检查点以帮助减少NameNode重启恢复时间，但**不能作为NameNode的热备份**。
### 4.3. 请简要说明Hadoop体系中的以下四个核心组件：HDFS、HBase、MapReduce 和 Hive 的基本概念，并分析它们在大数据处理过程中各自解决的关键问题。
>
**答案：**
**① HDFS**：是分布式文件系统，解决**海量数据的可靠存储**问题，通过将大文件分块并多副本冗余存储，提供高吞吐的读写访问。
**② MapReduce**：是分布式计算框架，解决**海量数据的并行处理**问题，通过“分而治之”的思想将任务分解为Map和Reduce阶段，在廉价集群上实现大规模计算。
**③ HBase**：是面向列的分布式NoSQL数据库，解决**海量数据的实时随机读写**问题，基于HDFS存储，支持毫秒级的数据查询与更新，适合非结构化或半结构化数据。
**④ Hive**：是基于Hadoop的数据仓库工具，解决**数据分析的易用性**问题，将SQL-like查询转换为MapReduce/Tez/Spark作业，降低普通用户使用Hadoop的门槛。
### 4.4. 给定一个文本文件，其内容如下。若使用MapReduce框架统计文件中每个单词的出现次数，请问Map函数和Reduce函数在整个执行过程中分别被调用多少次？请说明理由。
```
Hello Hello Hello
How are you
I am good
I am great
I am wonderful
```
>
**答案：**
Map 函数5次，Reduce 函数9次。【判断核心在于多少段文本、多少个不同的单词】
**① Map 次数**：Map函数根据输入文件的行进行调用，针对该文件中 5 行文本就会执行 5 次。
**② Reduce 次数**：上述所有单词按照<key, val>获取后，对重复的key去重，共计 9 个**不同的单词**。
### 4.5. 什么是分布式文件系统，它与本地文件系统的主要区别是什么？
>
**答案：**
本地文件系统管理的是**单机物理存储资源**，而分布式文件系统管理的是**跨网络的多机存储资源池**，通过软件层屏蔽底层分布细节，实现"本地体验、分布式能力"。
## 5. 论述题
### 5.1. 通用
基于 Hadoop/Spark 集群的人口普查数据分析与可视化，对 2005-2025 年各省人口、GDP、出生率、工资等多维度数据进行可视化分析。本项目利用 **HDFS 分层存储架构** 进行数据存储和分布式处理，结合 Django REST Framework 提供 API 服务，Spark 完成计算任务，前端 Vue 3 + ECharts 实现交互式数据可视化展示。

### 5.2. 数据
本项目数据获取基于 python requests 库，从国家统计局官网爬取数据，爬取下来的数据经过整理，过滤包含无效值的脏数据调整为 .csv 格式（如：population_data.csv），将数据上传至 HDFS 分布式文件系统，根据年份在 HDFS 上动态创建分区目录。

### 5.3. 后端
本项目后端基于 Django 框架，通过 PySpark 对 HDFS 中的分区数据进行分布式聚合分析与趋势预测，再由 Django REST Framework 对接口进行统一管理和序列化输出。
通过 `spark_client` 提交计算任务至 Spark 集群，将 HDFS 中的 CSV 数据加载为分布式 DataFrame，执行分组聚合（如各省人口汇总、GDP 增长率计算）后将结果返回前端，或缓存至 HDFS 结果目录供高频查询。
### 5.4. 前端

本项目前端基于 **Vue 3 + Vite** 构建，采用组合式 API（Composition API）实现响应式状态管理，结合 **ECharts 5.x** 完成多维度交互式数据可视化展示。
前端通过 **Axios** 统一封装 HTTP 请求，对接 Django REST API，实现数据的动态加载与图表实时渲染。采用 **Element Plus** 组件库构建布局，支持响应式适配与暗黑模式切换。
