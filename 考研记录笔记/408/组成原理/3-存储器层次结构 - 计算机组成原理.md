# 存储器层次结构

**计算机采用“存储程序”的工作方式，存储器相当于计算机的“仓库”**，数据和指令都存储在内存中，由于内存空间有限，许多数据需要放在外存中。

# 一、 存储器的分类

## 1.1. 按在计算机中的作用分类

![392](image/3-存储器层次结构%20-%20计算机组成原理/存储器间的交互01.png)

### 1.1.1. 主存储器(主存/内存)

用来存放计算机*运行期间*所需的**程序和数据**。
CPU 可直接*随机地*进行 **读/写访问**。
主存由 RAM 和 ROM 构成，**二者统一编址**。
**特点**：
- 容量较小；
- 存取速度较快；
- 价格较高。

### 1.1.2. 辅助存储器(辅存/外存)

用来存放当前暂时不用的程序和数据，以及一些需要**永久性保留**的信息。
辅助的内容需要*调入主存*后才能被 CPU 访问。
**特点**：
- 容量大；
- 存取速度较慢；
- 单位成本低。

### 1.1.3. 高速缓存存储器(Cache)

位于 **主存和 CPU之间**。
用来存放当前 **CPU 正在(经常)使用**的指令和数据，以便 CPU 能*高速地访问*他们。
现代计算机通常将其制作在 CPU 中。
**特点**：
- 速度可与 CPU 匹配；
- 存储容量小；
- 价格高。

## 1.2. 按存取方式分类

### 1.2.1. 随机存储器(RAM)
#408/组成原理/存储器/1-存储器分类/RAM 

存储器的任何一个存储单元都可以随机存取。
存取时间与存储单元的**物理位置无关**。
主要用于做**主存或高速缓冲存储器(Cache)**。
**特点**：
- 读写方便，使用灵活；
- RAM 分为 **静态RAM** 和 **动态RAM**；
- RAM 主要为用户编程设置的；
- **断电丢失存储信息**。

#### （一） 静态 RAM(SRAM)

**存储原理**：使用*双稳态触发器*（六晶体管结构）存储信息。
**特点**：
- 只要不断电，信息**不会丢失**，无需刷新。
- **速度快**（存取时间约几纳秒）。
- **集成度低**，功耗大，成本高。
- 主要用于 **Cache**和**快表TLB**。

#### （二） 动态 RAM(DRAM)

**存储原理**：使用*栅极电容*存储电荷来存储信息。
**特点**：
- 电容电荷会**泄漏**，需**定期刷新**（每隔 2ms/8ms 刷新一次）。
- **速度较慢**（比 SRAM 慢），但**集成度高**，功耗小，成本低。
- 主要用于**主存**。

### 1.2.2. 只读存储器(ROM)
#408/组成原理/存储器/1-存储器分类/ROM 
存储器的内容 **只能随机读出** 而 **不能写入**。
信息一旦写入 **就不变**，断电后也不消失。
通常用于存放固定不变的程序，常数和汉字字库。

特点：
- ROM 和 RAM **一起统一构成主存的地址域**；
- ROM 和 RAM 的存取方式 **均为随机存取**；
- 操作系统的内存储器：有*RAM*也有*ROM*;
- *广义上*的 ROM 现在可通过*电擦除*进行写入(*闪存和固态硬盘*)；
- ROM 存放**系统程序**，标准子程序和各类常数；
- *尽管有些可以写入，但写速度 < 读速度。*

### 1.2.3. 串行访问存储器

1. 顺序存取存储器(磁带)
	1. 存取数度慢；
	2. 必须顺着存储单元的**物理地址顺序**访问。
2. 直接存取存储器(磁盘、光盘)
	1. 既不是随机存取，也不是按顺序存取，*二者结合*；
	2. 先通过随机访问确定一个*较小的存储区域*，再在这个小区域内*顺序查找*；
	3. 存取时间同样与存取的物理地址相关。

### 1.2.4. 相联存储器

相联存储器也称按**内容访问存储器**，按照**内容和地址寻址**，其效率更高，造价更贵，如Cache、TLB。

## 1.3. 按信息可保持性分类

按照断电后存储器中的数据能否保留下来，可将存储器划分为 **易失性存储器和非易失性存储器**。
1. **易失性存储器**：断电后，存储信息消失(RAM)
2. **非易失性存储器**：断电后，信息仍保留(ROM、磁表面存储器、光存储器)

存储器的读出方式可分为 *破坏性读出*和*非破坏性读出*。
1. **破坏性读出**：读出后**若不恢复**，则存储器存储的**信息会丢失**。如磁芯存储器和DRAM的读出。
2. **非破坏读出**：**读出存储器内容时不会丢失信息**，因而就不需恢复数据。如SRAM、ROM、磁盘、磁带光盘。

## 1.4. 按存储介质分类(\*)

磁表面存储器：磁盘，磁带；
磁芯存储器；
半导体存储器：MOS 型存储器，双极型存储器；
光存储器：光盘。

# 二、 层次化存储器的基本结构

## 2.1. 存储器的主要性能指标
#408/组成原理/存储器/性能指标
[基本概念](<1-计算机系统概述 - 计算机组成原理.md#### （三） 存储器>) 
为区别存储体中的各个存储单元，给**存储单元的编号称为地址**。
> **寻址和编址区别**：
>  编址是给每个房间编号；
>  寻址是房间号已经有了，前台带找房间的*过程*。

对于 **字节编址** 的计算机，**最小寻址单位是一个字节**，*可以按 字节/半字/字 寻址*。
对于 **字编址** 的计算机，**最小寻址单位是一个字**，*仅支持按字寻址*。

![600](image/3-存储器层次结构%20-%20计算机组成原理/存储器的性能指标形象化.png)

### 2.1.1. 存储容量

对于 **字节编址的计算机**，以 **字节数来表示存储容量**，*现在大多数通用计算机都采用字节编址方式*。
对于 **字编址的计算机**，以 **字数与其字长的乘积** 来表示存储容量。
$$存储容量 = 存储字数 \times 字长$$ 
> **例如**：$1\text{M} \times 8\text{bit} = 1MB$  tips: $8bit = 1B$ 

**常用单位换算**：
- $1\text{G} = 1024\text{M}$；$1\text{M} = 1024\text{K}$
- $1\text{s} = 10^{3}\,\text{ms【毫秒】} = 10^{6}\,\mu\text{s【微秒】} = 10^{9}\,\text{ns【纳秒】} = 10^{12}\,\text{ps【皮秒】}$

| 概念       | 含义         | 对应寄存器      |
| :------- | :--------- | :--------- |
| **存储字数** | 存储器的地址空间大小 | MAR（地址寄存器） |
| **字长**   | 一次存取操作的数据量 | MDR（数据寄存器） |
存储字数表示存储器的地址空间大小【MAR】。
字长表示一次存取操作的数据量【MDR】。

![660](image/3-存储器层次结构%20-%20计算机组成原理/练习题-存储容量01.png)
> $可寻址单元数 = \frac{存储器总容量}{每个寻址单元的大小}，字=4B，半字=2B$ 
>  $=\frac{16 \ MB}{2 \ B}=\frac{16 \times 2^{20} \ B}{2 \ B} = 8 \times 2^{20} = 2^3 \times 2^{20} = 2^{23}$ 

### 2.1.2. 存取速度
存储器速度可用 **访问时间、存储周期或带宽** 来表示。
$${\color{red}数据传输率} = \frac{数据的宽度}{存储周期}$$  
> **注意**：数据传输率中的 K、M 是 10 的次方；**只有存储容量使用 2 的次方**。

| 性能指标           | 定义                        | 说明                             |
| :------------- | :------------------------ | :----------------------------- |
| **存取时间** $T_a$ | 从启动一次存储器操作到完成该操作所经历的全部时间  | —                              |
| **存取周期** $T_m$ | 存储器进行一次完整的读写操作所需的全部时间     | 包含**恢复时间**，故 $T_m > T_a$       |
| **主存带宽** $B_m$ | 数据传输率，即每秒从主存进出信息的**最大数量** | 单位：$\frac{\text{字}}{\text{秒}}$ |

#### （一） 访问时间

一般用 **读出时间 $T_A$** 及 **写入时间 $T_W$** 来描述。
- $T_A$：从存储器**接到读命令开始**至**信息被送到数据线上**所需的时间。
- $T_W$：存储器**接到写命令开始**至**信息被写入存储器**所需的时间。

#### （二） 存储周期

存储器进行一次读写操作所需要的 **全部时间**，也就是存储器进行连续读写操作所允许的 *最短间隔时间*。
它应该 **等于** 访问时间加下一次存取开始前所要求的附加时间，一般用 $T_M$ 表示。
> **注意**：存储周期 **大于** 存取时间，因为读写操作后需要一段**恢复内部状态的复原时间**。 

一般 $T_M$、$T_A$ 和 $T_W$存在以下关系：$T_M>T_A$，$T_M>T_W$。
![505](image/3-存储器层次结构%20-%20计算机组成原理/存储周期样例.png)

#### （三） 存储器的带宽

表示存储器**被连续访问时**可以提供的数据传送速率，通常用 **每秒传送信息的位数(或字节数)来衡量**。

![666](image/3-存储器层次结构%20-%20计算机组成原理/练习题-带宽01.png)
>$每次读取数据的宽度 = 16bit/8 = 2B$ 
 $T = 250ns = 250 x 10^{-9} s$ 
 $数据传输率 = \frac{宽度}{T} = \frac{2B}{250 \times 10^{-9}s} = 8 \times 10^6 \ B/s$ 

## 2.2. 存储器层次化结构

### 2.2.1. 主存储器的组成和基本操作

![504](image/3-存储器层次结构%20-%20计算机组成原理/主存储器的基本组成框图.png)

当 CPU 执行指令需访问主存时，**首先**把被访问单元**地址**送入**存储器地址寄存器(MAR)** 中；
**然后**通过地址线 **将主存地址送至主存的地址寄存器，地址译码器据此选中对应的存储单元**；
**同时**，CPU 通过控制线将 **读写信号** 送到主存的 **读写控制电路**。
- **写操作**：CPU **同时** 将要写的**信息送主存数据寄存器(MDR)中**，在读写控制电路的控制下，经数据线将信息写入选中的单元；
- **读操作**：主存读出 **选中单元的内容送数据线**，然后被送到MDR中。
> **注意**：**数据线的宽度和MDR的宽度相同，地址线的宽度和MAR的宽度相同**。
