# 存储器层次结构【\*非重点；※重点】

**计算机采用“存储程序”的工作方式，存储器相当于计算机的“仓库”**，数据和指令都存储在内存中，由于内存空间有限，许多数据需要放在外存中。

# 一、 存储器的分类

## 1.1. 按在计算机中的作用分类

![392](image/3-存储器层次结构%20-%20计算机组成原理/存储器间的交互01.png)

### 1.1.1. 主存储器(主存/内存)

用来存放计算机*运行期间*所需的**程序和数据**。
CPU 可直接*随机地*进行 **读/写访问**。
主存由 RAM 和 ROM 构成，**二者统一编址**。
**特点**：
- 容量较小；
- 存取速度较快；
- 价格较高。

### 1.1.2. 辅助存储器(辅存/外存)

用来存放当前暂时不用的程序和数据，以及一些需要**永久性保留**的信息。
辅助的内容需要*调入主存*后才能被 CPU 访问。
**特点**：
- 容量大；
- 存取速度较慢；
- 单位成本低。

### 1.1.3. 高速缓存存储器(Cache)

位于 **主存和 CPU之间**。
用来存放当前 **CPU 正在(经常)使用**的指令和数据，以便 CPU 能*高速地访问*他们。
现代计算机通常将其制作在 CPU 中。
**特点**：
- 速度可与 CPU 匹配；
- 存储容量小；
- 价格高。

## 1.2. 按存取方式分类

### 1.2.1. 随机存储器(RAM)
#408/组成原理/存储器/1-存储器分类/RAM 

存储器的任何一个存储单元都可以随机存取。
存取时间与存储单元的**物理位置无关**。
主要用于做**主存或高速缓冲存储器(Cache)**。
**特点**：
- 读写方便，使用灵活；
- RAM 分为 **静态RAM** 和 **动态RAM**；
- RAM 主要为用户编程设置的；
- **断电丢失存储信息**。

#### （一） 静态 RAM(SRAM)

**存储原理**：使用*双稳态触发器*（六晶体管结构）存储信息。
**特点**：
- 只要不断电，信息**不会丢失**，无需刷新。
- **速度快**（存取时间约几纳秒）。
- **集成度低**，功耗大，成本高。
- 主要用于 **Cache**和**快表TLB**。

#### （二） 动态 RAM(DRAM)

**存储原理**：使用*栅极电容*存储电荷来存储信息。
**特点**：
- 电容电荷会**泄漏**，需**定期刷新**（每隔 2ms/8ms 刷新一次）。
- **速度较慢**（比 SRAM 慢），但**集成度高**，功耗小，成本低。
- 主要用于**主存**。

### 1.2.2. 只读存储器(ROM)
#408/组成原理/存储器/1-存储器分类/ROM 

存储器的内容 **只能随机读出** 而 **不能写入**。
信息一旦写入 **就不变**，断电后也不消失。
通常用于存放固定不变的程序，常数和汉字字库。
**特点**：
- ROM 和 RAM **一起统一构成主存的地址域**；
- ROM 和 RAM 的存取方式 **均为随机存取**；
- 操作系统的内存储器：有*RAM*也有*ROM*;
- *广义上*的 ROM 现在可通过*电擦除*进行写入(*闪存和固态硬盘*)；
- ROM 存放**系统程序**，标准子程序和各类常数；
- *尽管有些可以写入，但写速度 < 读速度。*

### 1.2.3. 串行访问存储器

1. 顺序存取存储器(磁带)
	1. 存取数度慢；
	2. 必须顺着存储单元的**物理地址顺序**访问。
2. 直接存取存储器(磁盘、光盘)
	1. 既不是随机存取，也不是按顺序存取，*二者结合*；
	2. 先通过随机访问确定一个*较小的存储区域*，再在这个小区域内*顺序查找*；
	3. 存取时间同样与存取的物理地址相关。

### 1.2.4. 相联存储器

相联存储器也称按**内容访问存储器**，按照**内容和地址寻址**，其效率更高，造价更贵，如Cache、TLB。

## 1.3. 按信息可保持性分类

按照断电后存储器中的数据能否保留下来，可将存储器划分为 **易失性存储器和非易失性存储器**。
1. **易失性存储器**：断电后，存储信息消失(RAM)
2. **非易失性存储器**：断电后，信息仍保留(ROM、磁表面存储器、光存储器)

存储器的读出方式可分为 *破坏性读出*和*非破坏性读出*。
1. **破坏性读出**：读出后**若不恢复**，则存储器存储的**信息会丢失**。如磁芯存储器和DRAM的读出。
2. **非破坏读出**：**读出存储器内容时不会丢失信息**，因而就不需恢复数据。如SRAM、ROM、磁盘、磁带光盘。

## 1.4. 按存储介质分类

### 1.4.1. 磁存储器(\*)

磁存储器以 **磁性材料** 作为存储介质，主要包括 *磁芯、磁盘、磁带存储器*，目前广泛使用的磁盘、磁带中都包含机械装置，所以 *体积大、存取速度慢*，但磁存储器*单位容量成本最低*。

### 1.4.2. 光存储器(\*)

光存储器利用 **介质的光学特性** 读出数据，如 CD-ROM、DVD-ROM，用激光束照射盘面，靠盘面的不同反射率来读出信息，*光学存储器便于携带，成本低廉、适用于电子出版物的发行*。

### 1.4.3. 半导体存储器(※)
【在第三节部分补充】
**用半导体器件组成的存储器**。
#### （一） 半导体材料(\*)
根据导电性可分为三种材料，分别是 *可导电材料、绝缘体材料以及半导体材料*。
半导体材料在纯净状态下是**电绝缘体**(不导电)，通过掺杂微量的其他元素，*可以显著改变其导电性*，从而制造出 N 型或 P 型的半导体材料。

#### （二） 半导体器件(\*)
N 型和 P 型半导体材料可以构造出二极管、MOS 管等半导体器件。
二极管的特点是 *单向导通*，当电流从 P 进 N 出时导电，否则不导电。
![364](image/3-存储器层次结构%20-%20计算机组成原理/半导体器件.png)
MOS 管广泛应用于各种电子设备中，如电脑、手机等，它们在设备中扮演着 *开关或放大器* 的角色。
当 MOS 管用作开关时，可以通过 **改变栅极的电压来控制电流是否流过 MOS 管，从而控制电路的开关状态**。
![551](image/3-存储器层次结构%20-%20计算机组成原理/MOS管.png)

半导体存储器 *体积小、存储速度快，但单位容量成本相对较高*。目前主要有两大类：1. *双极型存储器*；2. 金属氧化物半导体，简称 **MOS存储器**。

(※)MOS 存储器分为 **静态 MOS 存储器(SRAM)** 和 **动态 MOS 存储器(DRAM)**。

# 二、 层次化存储器的基本结构

## 2.1. 存储器的主要性能指标
#408/组成原理/存储器/性能指标

[基本概念](<1-计算机系统概述 - 计算机组成原理.md#### （三） 存储器>) 
为区别存储体中的各个存储单元，给**存储单元的编号称为地址**。
> **寻址和编址区别**：
>  编址是给每个房间编号；
>  寻址是房间号已经有了，前台带找房间的*过程*。

对于 **字节编址** 的计算机，**最小寻址单位是一个字节**，*可以按 字节/半字/字 寻址*。
对于 **字编址** 的计算机，**最小寻址单位是一个字**，*仅支持按字寻址*。

![600](image/3-存储器层次结构%20-%20计算机组成原理/存储器的性能指标形象化.png)

### 2.1.1. 存储容量

对于 **字节编址的计算机**，以 **字节数来表示存储容量**，*现在大多数通用计算机都采用字节编址方式*。
对于 **字编址的计算机**，以 **字数与其字长的乘积** 来表示存储容量。
$$存储容量 = 存储字数 \times 字长$$ 
> **例如**：$1\text{M} \times 8\text{bit} = 1MB$  tips: $8bit = 1B$ 

**常用单位换算**：
- $1\text{G} = 1024\text{M}$；$1\text{M} = 1024\text{K}$
- $1\text{s} = 10^{3}\,\text{ms【毫秒】} = 10^{6}\,\mu\text{s【微秒】} = 10^{9}\,\text{ns【纳秒】} = 10^{12}\,\text{ps【皮秒】}$

| 概念       | 含义         | 对应寄存器      |
| :------- | :--------- | :--------- |
| **存储字数** | 存储器的地址空间大小 | MAR（地址寄存器） |
| **字长**   | 一次存取操作的数据量 | MDR（数据寄存器） |
存储字数表示存储器的地址空间大小【MAR】。
字长表示一次存取操作的数据量【MDR】。

![660](image/3-存储器层次结构%20-%20计算机组成原理/练习题-存储容量01.png)
> $可寻址单元数 = \frac{存储器总容量}{每个寻址单元的大小}，字=4B，半字=2B$ 
>  $=\frac{16 \ MB}{2 \ B}=\frac{16 \times 2^{20} \ B}{2 \ B} = 8 \times 2^{20} = 2^3 \times 2^{20} = 2^{23}$ 

### 2.1.2. 存取速度
存储器速度可用 **访问时间、存储周期或带宽** 来表示。
$${\color{red}数据传输率} = \frac{数据的宽度}{存储周期}$$  
> **注意**：数据传输率中的 K、M 是 10 的次方；**只有存储容量使用 2 的次方**。

| 性能指标           | 定义                        | 说明                             |
| :------------- | :------------------------ | :----------------------------- |
| **存取时间** $T_a$ | 从启动一次存储器操作到完成该操作所经历的全部时间  | —                              |
| **存取周期** $T_m$ | 存储器进行一次完整的读写操作所需的全部时间     | 包含**恢复时间**，故 $T_m > T_a$       |
| **主存带宽** $B_m$ | 数据传输率，即每秒从主存进出信息的**最大数量** | 单位：$\frac{\text{字}}{\text{秒}}$ |

#### （一） 访问时间

一般用 **读出时间 $T_A$** 及 **写入时间 $T_W$** 来描述。
- $T_A$：从存储器**接到读命令开始**至**信息被送到数据线上**所需的时间。
- $T_W$：存储器**接到写命令开始**至**信息被写入存储器**所需的时间。

#### （二） 存储周期

存储器进行一次读写操作所需要的 **全部时间**，也就是存储器进行连续读写操作所允许的 *最短间隔时间*。
它应该 **等于** 访问时间加下一次存取开始前所要求的附加时间，一般用 $T_M$ 表示。
> **注意**：存储周期 **大于** 存取时间，因为读写操作后需要一段**恢复内部状态的复原时间**。 

一般 $T_M$、$T_A$ 和 $T_W$存在以下关系：$T_M>T_A$，$T_M>T_W$。
![505](image/3-存储器层次结构%20-%20计算机组成原理/存储周期样例.png)

#### （三） 存储器的带宽

表示存储器**被连续访问时**可以提供的数据传送速率，通常用 **每秒传送信息的位数(或字节数)来衡量**。

![677](image/3-存储器层次结构%20-%20计算机组成原理/练习题-带宽01.png)
>$每次读取数据的宽度 = 16 \ bit \ / \ 8 = 2B$ 
 $T = 250ns = 250 \times 10^{-9} s$ 
 $数据传输率 = \frac{宽度}{T} = \frac{2B}{250 \times 10^{-9}s} = 8 \times 10^6 \ B/s$ 

## 2.2. 存储器层次化结构

### 2.2.1. 主存储器的组成和基本操作

![504](image/3-存储器层次结构%20-%20计算机组成原理/主存储器的基本组成框图.png)

当 CPU 执行指令需访问主存时，**首先**把被访问单元**地址**送入**存储器地址寄存器(MAR)** 中；
**然后**通过地址线 **将主存地址送至主存的地址寄存器，地址译码器据此选中对应的存储单元**；
**同时**，CPU 通过控制线将 **读写信号** 送到主存的 **读写控制电路**。
- **写操作**：CPU **同时** 将要写的==**信息==送主存数据寄存器(MDR)中**，在读写控制电路的控制下，经数据线将信息写入选中的单元；
- **读操作**：主存读出 **选中单元的内容送数据线**，然后被送到MDR中。
> **注意**：**数据线的宽度和MDR的宽度相同，地址线的宽度和MAR的宽度相同**。

### 2.2.2. 存储器的层次化结构

存储器的**速度越快**，往往**容量越小**，**越靠近CPU**。
CPU 执行指令时，需要的操作数大部分都来自寄存器。

**层次结构**：Cache <-①-> 主存层和主存 <-②-> 辅存
①解决 **CPU 和主存速度不一致的问题**；②解决 **存储系统的容量问题**。

**层次思想**：上一层的存储器作为低一层存储器的高速缓存，上一层的内容是下一层内容的一部分。即：*数据一般只在相邻两层之间复制传送，总是从慢速 -> 快速存储器被使用，传送的单位是一个定长块*。

![](image/3-存储器层次结构%20-%20计算机组成原理/存储器层次化结构.png)
> Cache 和主存能与 CPU 直接交换信息；辅存要通过主存与 CPU 交换信息；主存与 CPU，Cache，辅存都能交换信息。

主存和 Cache 之间的数据调动是由 *硬件* 自动完成的，**对所有程序员透明**；
主存与辅存之间的数据调动是由 *硬件与os* 共同完成的【换入换出技术】，**对所有程序员透明**。

# 三、 主存储器

## 3.1. RAM 的存储原理

**存储元(元件)**：用于存储 **一位** 二进制数据（`0`或`1`）的电子器件，**是存储器中最小的存储单位**。
>当选中某个存储单元时，实际上是通过 **字线** 来控制多个存储元，进而**读出或写入数据**。

### 3.1.1. DRAM 的工作原理

动态随机存取存储器的 **每个存储元通常由 1 个电容和 1 个MOS管构成**。

当 DRAM 中某个电容存储的电荷数**达到或超过阈值**时(*简单理解为电量*)，该电容所在的存储元 **表示 1**，否则表示 0。

**读写过程**：
- **读操作**：通过 MOS 管读取电容上的电荷量（有无电荷），经敏感放大器放大后输出数据。由于读取过程会破坏电容中的原始电荷，因此读操作后必须进行 **重写/再生**（即破坏性读出）。
- **写操作**：通过 MOS 管对电容进行充电（写 `1`）或放电（写 `0`）。
**刷新**：
- 电容上的电荷会随时间**泄漏**，即使不断电信息也会丢失，因此需要 **定时刷新**（通常每隔 2ms 或 8ms 刷新一次）。
- **刷新单位**：以 **行** 为单位刷新，每次刷新一行中的所有存储元。
- **刷新方式**：由内部刷新计数器自动提供行地址，无需外部地址输入，刷新时不影响存储体内的正常读/写操作（但会占用一定时间）。
- **刷新与读写的区别**：刷新是按行重写，相当于“读后再生”过程，但刷新时不需要外部地址，也不输出数据到数据线，仅用于维持电荷。

### 3.1.2. DRAM 与 SRAM 对比

静态随机存储器(SRAM)中，**静态**：指即使信息被读出后，它仍**保持其原状态**而不需要再生(非破坏性读出)，**也不需要不断刷新**。

动态随机存储器(DRAM)中，利用存储元的**电容**来存储信息，电容上的电荷会随时间泄漏，因此需要定时刷新。

|                                                        | <font color="#4bacc6">SRAM(Static Random Access Memory)</font> | <font color="#9bbb59">DRAM(Dynamic Random Access Memory)</font> |
| :----------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------- |
| **主要用途**                                               | <font color="#4bacc6">Cache</font>                             | <font color="#9bbb59">主存</font>                                 |
| **存储信息**                                               | <font color="#4bacc6">双稳态触发器，6个MOS管</font>                     | <font color="#9bbb59">电容，1个MOS管</font>                          |
| **破坏性读出**                                              | <font color="#4bacc6">非</font>                                 | <font color="#9bbb59">是</font>                                  |
| **再生**                                                 | <font color="#4bacc6">不需要</font>                               | <font color="#9bbb59">需要</font>                                 |
| **行列地址是否复用**                                           | <font color="#4bacc6">否</font>                                 | <font color="#9bbb59">是</font>                                  |
| **引脚数量**                                               | <font color="#4bacc6">较多</font>                                | <font color="#9bbb59">较少</font>                                 |
| **需要刷新**                                               | <font color="#4bacc6">不要</font>                                | <font color="#9bbb59">需要</font>                                 |
| [**送行列地址**](<3-存储器层次结构 - 计算机组成原理.md### 3.2.2. 译码驱动方式>) | <font color="#4bacc6">同时送</font>                               | <font color="#9bbb59">分两次送(复用)</font>                           |
| **运行速度**                                               | <font color="#4bacc6">快</font>                                 | <font color="#9bbb59">慢</font>                                  |
| **集成度**                                                | <font color="#4bacc6">低</font>                                 | <font color="#9bbb59">高</font>                                  |
| **存储成本**                                               | <font color="#4bacc6">高</font>                                 | <font color="#9bbb59">低</font>                                  |
![546](image/3-存储器层次结构%20-%20计算机组成原理/练习题-SRAM与DARM.png)
> A: SRAM 依靠双稳态触发器暂存，DRAM 依靠电容暂存；
> B: DRAM 依靠双稳态电路的稳定状态；
> C: SRAM 速度快，但集成度低，因为由6个MOS管构成；DRAM 速度慢，但集成度高，因为仅由一个MOS管构成；
> D: **正确**，根据MOS管的数量来判断速度与集成度。越多越快，越少集成度越高。

- **地址复用**：DRAM 采用地址复用技术，行地址和列地址分两次通过同一组地址引脚输入，目的是减少芯片的引脚数量（如 1K×1 芯片只需 10 条地址线，而非 20 条）。
- **刷新开销**：DRAM 需要定期刷新（典型周期为 2ms 或 8ms），约占 1%~2% 的时间开销。
- **SRAM 静态含义**：“静态”并非指速度慢，而是指信息一旦写入，只要不断电就能无限期保持，无需刷新操作。

## 3.2. 半导体存储芯片
#408/组成原理/存储器/2-半导体随机存储器 
### 3.2.1. 基本结构(\*)

一个半导体存储器的基本结构包括 **存储矩阵、译码驱动电路、IO/读写电路和控制电路**，此外半导体存储器还与 *地址线、数据线、片选线和读写控制线* 相连。

![](image/3-存储器层次结构%20-%20计算机组成原理/半导体存储芯片结构.png)

**各组成部分功能**：

| 组成部分          | 功能说明                                   |
| :------------ | :------------------------------------- |
| **存储矩阵(存储体)** | 由大量存储单元排列成矩阵形式（行×列），每个存储单元存放1位二进制数据    |
| **地址译码器**     | 将地址线输入的二进制地址转换为对应的行/列选择信号，选中指定的存储单元    |
| **驱动电路**      | 增强译码器输出的驱动能力，确保能有效驱动选中的存储单元            |
| **I/O电路**     | 负责数据的输入/输出缓冲，以及读/写放大（对于DRAM还需包含敏感放大器）  |
| **控制电路**      | 接收片选信号（CS）和读写控制信号（WE/OE），产生内部操作时序和控制逻辑 |

**引脚信号分类**：

| 信号类型            | 说明                                         | 方向  |
| :-------------- | :----------------------------------------- | :-- |
| **地址线**         | 输入片内地址，用于选择存储单元。$芯片容量 = 2^(地址线数) × 数据线位数$  | 输入  |
| **数据线**         | 传输读写数据的通道，位数等于芯片字长                         | 双向  |
| **片选线（CS/CE）**  | 选择当前芯片，高/低电平有效。多个芯片共用总线时用于区分               | 输入  |
| **读RD/写WR 控制线** | 控制操作类型（WE=低电平写，OE=低电平读）                    | 输入  |
| **电源线**         | 供电（Vcc）和接地（Vss）                            | -   |

**引脚数目计算**：
- 芯片总引脚数 = 地址线数 + 数据线数 + 片选线(1) + 读写控制线(1~2) + 电源/地线(2)
- 例如：16K×8位芯片 → $地址线数 = log_2 16K=14$ 条，数据线=8条，加上控制线，总引脚约 14+8+1+1+2=26条

> **注意**：
>   1. DRAM 常采用 **地址复用** 技术（行/列地址分时输入），实际地址引脚数约为非复用方式的一半，但需要额外引入行地址选通信号RAS和列地址选通信号CAS。
>   2. 片选线是 **多个芯片共享总线实现容量扩展** 的关键，避免总线冲突。
>   3. 芯片的 **存储容量** = 存储单元总数 × 每个单元的位数 = $2^{地址线数} \times 数据线位数$。

### 3.2.2. 译码驱动方式

译码驱动电路：负责将 CPU 传来的 **地址信号翻译** 成对 **特定存储单元的选择信号**。
#### （一） 线选法(单译码法)

**地址译码器只有一个**。**线选法只适用于容量小的静态存储器(SRAM)**。

通过 **n 个地址引脚** 可定义一个大小为 $2^n$ 的 **地址空间**，即译码器的输入端为 n 根引脚的情况下，其输出端的引脚个数为 $2^n$ 个。
> **示例**：地址输入线引脚数 n=4 时，经地址译码器译码，可译出 $2^4=16$ 个状态，分别对应 16 个地址，16 个存储单元的地址为 0000B ~ 1111B。

![228](image/3-存储器层次结构%20-%20计算机组成原理/单译码结构.png)
> **缺点**：译码后输出线的数量过多（$2^n$ 条），当容量较大时，译码输出线数量庞大，导致芯片内部布线复杂、面积增大。
> **注意**：线选法的输出线直接连接到存储单元的选通端，每个输出线对应一个独立的存储单元。

#### （二） 重合法(双译码法)

**解决线选法存在的缺陷**。适用于 **大容量的动态存储器(DRAM)**。

重合法的原理类似*笛卡尔坐标系*，实数对 (X, Y) 能够唯一确定 1 个存储单元，实数对中的 X 由 **行地址译码驱动** 来译码，Y 由 **列地址译码驱动** 来译码。

**地址划分**：将 n 位地址分为行地址和列地址两部分，通常各占 n/2 位。
**引脚数量**：
- 行地址线：n/2 根 → 译码输出 $2^{n/2}$ 条行选择线
- 列地址线：n/2 根 → 译码输出 $2^{n/2}$ 条列选择线
- **总输出线数**：$2^{n/2} + 2^{n/2} = 2^{(n/2)+1}$ 条
相比之下，线选法需要 $2^n$ 条输出线。重合法可大幅减少译码输出线的数量。
> **示例**：n=10 时
> - 线选法需要 $2^{10}=1024$ 条输出线
> - 重合法需要 $2^{5}+2^{5}=32+32=64$ 条输出线

![223](image/3-存储器层次结构%20-%20计算机组成原理/双译码结构.png)
> **注意**：DRAM 常结合地址复用技术，将行地址和列地址分时送入芯片，进一步减少地址引脚数。

DRAM 一般使用 **行列地址复用技术**，而SRAM 一般使用 **行列独立技术**。
- **行列地址复用技术**：使用重合法时 *分先后两次* 将存储矩阵的行列地址传入译码驱动电路；
- **行列独立技术**：一次性传递整个访问地址，*地址线数量不减半*。

**DRAM 地址复用过程**：

![284](image/3-存储器层次结构%20-%20计算机组成原理/DRAM地址复用样例.png)
> 以 16×4bit DRAM 芯片为例，该芯片由 4 个位平面构成，每个位平面的存储阵列为 4 行 × 4 列。一个存储单元存放 4 位数据，故数据线线数为 4。另外，DRAM 芯片内部具有 **行缓冲**。
由于采用行列地址复用，传送地址时：
> 1. **送行地址**：先传送 2 位行地址，选中某一行，并将该行的 4 个位平面中的数据（共 16 位）读出到 **行缓冲**（即 4×4=16 位宽）。
> 2. **送列地址**：再传送 2 位列地址，由列地址从行缓冲中选中某一列（4 个位平面各提供 1 位，共 4 位），通过数据线输出。
**行缓冲**：暂存读出的整行数据，避免对同一行的多次读操作重复访问存储阵列。

![668](image/3-存储器层次结构%20-%20计算机组成原理/练习题-译码驱动01.png)
> DRAM 双译码结构-行列地址复用。
> 8bit -> 8 条数据线；64M ->$2^6 \ \times \ 2^{20} = 2^{26}$ -> $2^{13} \times 2^{13}$ 
> 13 地址线，8 数据线。

### 3.2.3. DRAM 的刷新

电容会 **漏电**，所以 DRAM 的单个存储单元必须时常 **刷新**，否则会因为漏电发生 **数据丢失**。
**刷新以 ”行“ 为单位**：对 DRAM 中某一行的 *全体电容* 先读取一次数据，再写入一次数据(*假读*)。

为确保数据不会丢失，每一行的刷新时间间隔通常不超过 2ms，对同一行进行 **相邻两次刷新** 的 *时间间隔* 称为**刷新周期**。刷新一行的时间一般等于 **存储周期**。

**刷新操作由内存控制器负责**。刷新地址计数器至少 2 位。
存储器由多个芯片构成时，所有芯片 **同时按行刷新**。

> **注意**：刷新对 CPU 是透明的。
> 
> **内存争用**：刷新时的 DRAM **不能响应** CPU 的访问，所以 CPU 访问内存和内存控制器刷新操作存在内存争用。
>    解决方式：**集中刷新、分散刷新、异步刷新**。

> **例子**：假设动态存储器 存储体为 128行x128列结构，存储器的读写周期(存储周期) tc=0.5us，刷新间隔为2ms，因此 **2ms 内应完成所有128行的刷新**。
> 2ms/0.5us = 4000 个存储周期。

#### （一） 集中刷新

在一个刷新周期内，集中一段时间对**所有行逐行刷新**，其余时间全部用于**读写或保持**(维持当前数据状态保持不变)。
对于上述列子，集中刷新方式如下：
- 前 `3872` 个读写周期都用来进行 **读写/保持**，后 `128` 个读写周期集中用于刷新。
![660](image/3-存储器层次结构%20-%20计算机组成原理/集中刷新方式.png)
> **优点**：读写操作期间不会受刷新操作的影响，速度较快；
> **缺点**：存在较长时间的“死区”，即在集中刷新的读写周期内，CPU长时间无法访问存储器。
> **存储器芯片的内部行数越多，“死区”的时间越长**。

#### （二） 分散刷新

将刷新操作分散到每个存储周期中，将存储周期拉长。存储周期tc变为tc'，每个存储周期分为两部分：前半部分用于 *读写(tc)*，后半部分用于 *刷新(tr)* 一行。
对于上述例子，分散刷新方式如下：
- 每个 tc'，**前半段**用来进行读写或保持操作，**后半段用作刷新，因此tc'=1s**。
- 每过 128 个 tc'，整个存储器就被刷新一次，**在 2ms 内可进行约 15 次刷新**。
![605](image/3-存储器层次结构%20-%20计算机组成原理/分散刷新方式.png)
> **优点**：不存在“死区”，CPU 可以在每个周期的读写阶段随时访问存储器；
> **缺点**：因增加了刷新时间，存储周期变长，系统运行速度降低。刷新次数过于频繁，造成不必要的刷新开销。

#### （三） 异步刷新

集中刷新和分散刷新的结合。在刷新周期内，将刷新操作 **均匀分布** 到各个时间段，每隔 **固定时间** 刷新一行。
对于上述例子，异步刷新方式如下：
- 将 128 次刷新**平均分散**在 2ms 的时间内，**每隔一段时间刷新一行**。(2ms 被分为 128 个 15.625us 的时间段)
- 将每个时间段中 **最后的 0.5us** 用来刷新一行。
![596](image/3-存储器层次结构%20-%20计算机组成原理/异步刷新方式.png)
> **优点**：减少“死区”的连续长度(每次仅阻塞一个存储周期)，**避免 CPU 连续等待过久**。

> **注意**：由于动态存储器DRAM 的刷新是按行进行，为减少刷新周期，可以**减少存储矩阵的行数，增加列数**。
> ==**刷新以行为单位**==，逐行顺序地恢复数据，**再生** 仅恢复 **被读出** 的那个单元的数据。

| 对比项      | 集中刷新       | 分散刷新      | 异步刷新           |
| :------- | :--------- | :-------- | :------------- |
| **死区**   | 有（连续长时间）   | 无         | 有（短暂，分布均匀）     |
| **存储周期** | 正常         | 延长        | 正常             |
| **刷新频率** | 正常（每周期一次）  | 过高（每周期都刷） | 适中             |
| **控制逻辑** | 简单         | 简单        | 稍复杂            |
| **适用场景** | 早期系统       | 低速系统      | **现代 DRAM 主流** |
| **考频**   | 高（需计算死时间率） | 中         | 高（理解原理）        |
> **注意**：408 考试中常给出行数、存储周期、刷新间隔，要求计算集中刷新的“死时间率”，或判断采用哪种刷新方式更合理。需重点掌握集中刷新和异步刷新的原理与计算。

### 3.2.4. DRAM 的读写信号时序(\*)

读(写)周期时间表示DRAM芯片进行两次连续读(写)操作时所**必需间隔的时间**。

![](image/3-存储器层次结构%20-%20计算机组成原理/DRAM读写信号时序.png)

**主要控制信号说明**：

| 信号 | 全称 | 电平有效 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **RAS** | Row Address Strobe | 低电平有效 | 行地址选通信号。当 RAS 为低电平时，声明当前地址线上的信号为**行地址** |
| **CAS** | Column Address Strobe | 低电平有效 | 列地址选通信号。当 CAS 为低电平时，声明当前地址线上的信号为**列地址** |
| **WE** | Write Enable | 高电平读 / 低电平写 | 读写控制信号。高电平时执行**读操作**，低电平时执行**写操作** |
| **地址线** | Address Bus | - | 先传输**行地址**（与 RAS 同步），后传输**列地址**（与 CAS 同步） |
| **数据线** | Data Bus | - | 读操作时输出已读出的数据，写操作时输入待写入的数据 |
**读操作时序过程**：
1. **送行地址**：地址线先放置行地址，、$\overline{RAS}$ 变为低电平，锁存行地址。
2. **送列地址**：经过一段时间延迟（$t_{RCD}$），地址线再放置列地址，$\overline{CAS}$ 变为低电平，锁存列地址。
3. **读操作**：$\overline{WE}$ 保持高电平（读模式），DRAM 内部将选中存储单元的数据读出到数据线。
4. **数据输出**：$\overline{CAS}$ 变低后经过一定延迟（$t_{CAC}$），数据线上出现有效数据。
5. **恢复**：$\overline{RAS}$ 和 $\overline{CAS}$ 先后变高，地址线恢复，完成一次读周期。
**写操作时序过程**：
6. **送行地址**：地址线先放置行地址，$\overline{RAS}$ 变低，锁存行地址。
7. **送列地址**：地址线再放置列地址，$\overline{CAS}$ 变低，锁存列地址。
8. **写操作**：$\overline{WE}$ 变低（写模式），数据线预先放置待写入数据。
9. **数据写入**：$\overline{CAS}$ 变低期间，DRAM 将数据线数据写入选中存储单元。
10. **恢复**：$\overline{RAS}$ 和 $\overline{CAS}$ 先后变高，地址线和数据线恢复，完成一次写周期。
> **注意**：
>   1. $\overline{RAS}$ 和 $\overline{CAS}$ 信号是 DRAM 区别于 SRAM 的关键控制信号，体现了**地址分时复用**的特点。
>   2. 读操作和写操作的主要区别在于 **WE 信号的电平** 以及 **数据线上数据传输的方向**。
>   3. 存储周期（$t_{RC}$） = 读/写周期时间，通常大于存取时间（$t_{CAC}$），因为需要包含信号恢复时间。
>   4. 408 考试中，本节内容通常以**选择题**形式考查信号功能辨析，较少考查具体时序参数计算。

![](image/3-存储器层次结构%20-%20计算机组成原理/练习题-读写周期.png)
> $2 \ ms = 10^3 \ \mu s$ $\frac{2 \ ms}{128 \ 行} = 15.625 \ \mu s$ 
> 则先安排 15.425us 时间用于读写操作，最后0.2us用于刷新。
> $\frac{15 \ \mu s}{0.2 \ \mu s} = 75$; $\frac{16 \ \mu s}{0.2 \ \mu s} = 80$ 理想状态下读写次数大致范围在(75~80)，读写次数只能尽可能小，不能大。D

### 3.2.5. ROM 存储器

ROM 中一旦有了信息，就不能轻易改变，即使掉电也不会丢失。
ROM 和 RAM 都是支持 **随机存取** 的存储器。
#### （一） ROM 的主要类型

| 类型               | 全称           | 可编程次数     | 擦除方式     | 特点                                          |
| :--------------- | :----------- | :-------- | :------- | :------------------------------------------ |
| **MROM**         | 掩模式只读存储器     | 0 次（出厂固化） | 不可擦除     | 可靠性高、成本低，但灵活性差                              |
| **PROM**         | 一次可编程只读存储器   | 1 次       | 不可擦除     | 允许用户一次性写入，写入后不可更改                           |
| **EPROM**        | 可擦除可编程只读存储器  | 多次        | 紫外线擦除    | 可多次改写，但编程次数有限，写入时间较长                        |
| **EEPROM**       | 电可擦除可编程只读存储器 | 多次        | 电擦除（字节级） | 可在电路中在线擦除和改写，但速度慢于 RAM                      |
| **Flash Memory** | 闪存           | 多次        | 电擦除（块级）  | 非易失性，写入前需先擦除（写慢读快），如 U 盘、SD 卡               |
| **SSD**          | 固态硬盘         | 多次        | 电擦除（块级）  | 基于 Flash 芯片，由控制单元 + 存储单元(Flash芯片)组成，读写快、功耗低 |
> **注意**：
>   1. ROM 的“只读”是历史叫法，现代多数 ROM（如 Flash、EEPROM）支持多次写入，只是写入方式比 RAM 复杂。
>   2. 区别 RAM 和 ROM 的核心在于 **是否易失**，而非是否可写。
>   3. Flash 和 SSD 虽然可读可写，但在存储层次中仍归类为 ROM 类（非易失性存储器）。
>   4. 408 考试中，本节通常以 **选择题** 形式考查各类型 ROM 的特性对比。

### 3.2.6. SDRAM 的特点(\*)

SDRAM（同步动态随机存储器）是现代计算机主存的核心芯片，其工作方式与传统 DRAM 有所不同。
**与传统 DRAM 的区别**：

| 对比项 | 传统 DRAM | SDRAM |
| :--- | :--- | :--- |
| **数据传输方式** | 异步（与 CPU 时钟无关） | 同步（受系统时钟控制） |
| **工作频率** | 较低 | 较高 |
| **突发传送** | 不支持 | 支持 |
**SDRAM 的核心特性**：
- **同步传输**：读写操作与系统时钟同步，无需插入等待周期。
- **突发传送（Burst Transfer）**：
  - 第一次存取时给出首地址，同一行的所有数据被送入 **行缓冲器**（通常由 SRAM 实现，大小为列数 × 存储单元位数）。
  - 后续每个时钟周期可从行缓冲器连续输出一个数据。
- **可编程工作模式**：通过内部工作方式寄存器可设置：
  - **突发长度**：一次突发传送的数据个数
  - **CAS 延迟**：从收到读命令到开始传送数据的延迟时间（CL 值）
> **注意**：
>   1. SDRAM 的“同步”指其时钟与 CPU 总线时钟同步，因此可以工作在更高的频率。
>   2. 行缓冲器（Row Buffer）是 SDRAM 实现高带宽的关键，当访问在同一行时，只需一次行激活，后续列访问直接从行缓冲器读取。
>   3. 408 考试中，本节内容通常以 **选择题** 形式考查 SDRAM 与传统 DRAM 的区别，以及突发传送的基本概念。

# 四、 主存容量扩展与并行技术

## 4.1. 主存容量的扩展

### 4.1.1. 位扩展

位扩展称为：**字长扩展** 或 **数据总线扩展**，当存储芯片的数据总线 **位宽小于** CPU 的数据总线位宽时，采用位扩展的方式。
> **例子**：假设利用 `256Kx1位` 的SRAM 存储芯片组成 `256Kx8位` 的存储器并于 CPU 连接，需要8/1=8个SRAM芯片。
>   1. 将8个存储芯片的地址线(18根=$2^8 \times 2^{10} = 2^{18}$)、读写控制线与CPU的地址线与读写控制线相连；
>   2. 将所有存储芯片的 **片选端** 与 **CPU的MREQ#信号** 相连，只有这样才能保证8个芯片同时被选中；
>   3. 将 8 个存储芯片的数据线分别连到 CPU 的 8 位数据线上。

![](image/3-存储器层次结构%20-%20计算机组成原理/位扩展示例.png)
- $\overline{MREQ}$：高低电平均有效，$\overline{CS}$片选端低电平用来选中存储芯片，高电平补选中存储芯片。
- $\overline{WE}$：读写信号，高电平读，低电平写。

> **注意**：真题一般采用 RAM 或 SRAM 存储芯片，因其单译码结构较为简单。

### 4.1.2. 字扩展

字扩展称为：**容量扩展** 或 **地址总线扩展**，当存储器的 **字数** 不能满足存储器的要求时，采用子扩展方式。

#### （一） 线选法进行字扩展

- **每次只能有一位片选地址有效**（即只能有一位高位地址为 `0`）
- **不允许同时多位有效**，否则会导致多个芯片同时被选中，造成数据冲突
- 可以保证 **每次寻址只选中一个芯片**。

> **例子**：假设利用 `16Kx8位` 的SRAM存储芯片组成 `64Kx8位` 的存储器并与CPU连接，需要 `64K/16K=4`个SRAM芯片。
>   1. 与CPU进行连接时，16K的芯片对应14根地址线($2^4 \times 2^{10}=2^{14}$)，CPU访问64K的主存容量需要 **18根** 地址线($2^8 \times 2^{10}=2^{18}$)；
>   2. 可以将 **高4位地址** $A_{17 \sim 14}$ 分别连接到 4 个SRAM芯片的**片选信号 CS 端**。

![641](image/3-存储器层次结构%20-%20计算机组成原理/字扩展-线选法示例图.png)

- **优点**：不需要地址译码器，**线路简单**；
- **缺点**：**地址空间不连续**；选片的地址线必须**分时为低电平**(否则不能工作)；不能充分利用系统的存储空间，造成**地址资源的浪费**。

#### （二） 译码片选法进行字扩展

- 用除片内寻址之外的 **高位地址线** 通过 **地址译码器** 产生片选信号。如：`16Kx8位`的SRAM存储芯片组成`64Kx8位`需要4个片选信号。
- 仅需要2位用于片选，则 $A_{15}A_{14}=00$ 时，选中第一片， $A_{15}A_{14}=01$ 时选中第二片，以此类推。

> **例子**：假设利用 `16Kx8位` 的SRAM存储芯片组成 `64Kx8位` 的存储器并与CPU连接，需要 `64K/16K=4`个SRAM芯片。
>   1. 与CPU进行连接时，16K的芯片对应14根地址线，CPU访问64K的主存容量需要 **16根** 地址线；
>   2. 可以将 **高2位** 地址 $A_{15 \sim 14}$ 送入 **2:4译码器输入端**，将 2:4译码器的四个输出**分别连接**到4个SRAM芯片的**片选信号CS端**；
>   3. 将 CPU 内存请求信号 MREO# 连接到**译码器使能端**，只有进行存储访问时，译码器才能进行工作，否则译码器输出全`0`(假设高电平有效)，所有存储芯片均不被选中。

![602](image/3-存储器层次结构%20-%20计算机组成原理/字扩展-译码片选法示例图.png)

> **注意**：加入译码器后，**地址分配连续**。

### 4.1.3. 字位扩展

存储芯片的 **字数与字长均不能满足** 存储器的数据位和存储总容量要求时，采用 **字位同时扩展** 方式。

> **例子**：假设利用 8片 `16Kx4位` 的 RAM芯片组成 `64Kx8位` 的存储器。
> 每两片构成一组 `16K×8位` 的存储器(**位扩展**)，4组便构成 `64K×8位` 的存储器(**字扩展**)。
> 地址线 $A_{15}A_{14}$ 经译码器得到 4 个片选信号：
>   1. $A_{15}A_{14}=00$ 时，输出端 0 有效，选中第一组的芯片(①和②)；
>   2. $A_{15}A_{14}=01$ 时，输出端 1 有效，选中第二组的芯片(③和④)，以此类推。

![](image/3-存储器层次结构%20-%20计算机组成原理/字位扩展-示例图.png)

> **注意**：字位扩展的配置顺序不限制，但是便于理解 **优先确定位扩展，再确定字扩展**。

![](image/3-存储器层次结构%20-%20计算机组成原理/练习题-字位扩展.png)
> 按照位扩展，则需要8/1=8块 16Kx1位芯片；按照字扩展，则需要64K/16K=4组 16Kx8位芯片。
> 则字方向扩展4倍，位方向扩展8倍。D

## 4.3. 主存与CPU的连接

- **信号线连接**：地址线、数据线、读写控制线、片选线
- **地址分配**：
  - 低位地址 → 片内寻址（连接芯片地址引脚）
  - 高位地址 → 片选译码（选择芯片）
- **片选信号产生方式**：
  - 线选法：直接用高位地址线作为片选
  - 译码器法：高位地址经译码器产生片选信号
- **连接图设计步骤**：
  1. 计算所需芯片数量与类型
  2. 确定地址分配方案（高位/低位位数）
  3. 连接公共总线（地址、数据、读写控制）
  4. 设计片选逻辑电路
- **地址空间分析**：根据片选逻辑判断主存地址分配是否连续
