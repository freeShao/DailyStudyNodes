# 一、 计算机系统层次结构

## 1.1. 计算机系统的基本组成

**硬件系统** 和 **软件系统** 共同构成了一个完整的计算机系统。

- **硬件**：指有形的物理设备，是计算机系统中实际物理装备的总称；
- **软件**：指在硬件上运行的程序和相关的数据及文档；
- **逻辑功能**：对某一功能来说，若其既可用软件实现，又可用硬件实现，则称软/硬件在 **逻辑功能** 上是 **等价** 的。

## 1.2. 计算机硬件的基本结构

### 1.2.1. 诺伊曼机基本思想

冯 · 诺依曼机是一种采用 **存储程序** 概念的计算机体系结构。[是SISD体系结构](<5-中央处理器 - 计算机组成原理.md## 7.1. SISD、SIMD、MIMD、向量处理器>)，其每次执行一条指令、一条数据。
**核心思想：存储程序控制**，将程序和数据以二进制形式存放在存储器中，计算机自动逐条执行指令。

**特点**：
1. 采用 **存储程序** 的工作方式；
2. 计算机硬件系统由 **运算器**、**存储器**、**控制器**、**输入设备** 和 **输出设备** 5大部件组成；
3. **指令** 和 **数据** 以 **同等地位存储** 在存储器中，形式上没有区别，但计算机应能区分它们；
4. 指令和数据均用 **二进制代码** 表示；
5. 指令由 **操作码** 和 **地址码** 组成，操作码指出 **操作的类型**，地址码指出 **操作数的地址**。

### 1.2.2. 计算机的功能部件

**计算机由五大基本部件组成**：输入设备、输出设备、存储器、运算器、控制器。

#### （一） 输入设备

主要功能是将 **程序** 和 **数据** 以机器所能识别和接受的信息形式输入计算机。例：鼠标、键盘、摄像机。

#### （二） 输出设备

将计算机处理的结果以人们所能接受的形式或其他方式。例：显示器、打印机、音响。

#### （三） 存储器

存储程序和数据，是计算机的 **记忆装置**。分为主存和外存两部分。

1. **主存储器（内存储器/主存）**：直接与 **CPU** 交换信息，按地址访问，速度快，容量较小，**断电后信息丢失**。例：RAM。
	1. **存储体**：由 **许多的存储单元** 组成，每个单元有 **唯一的地址**，每个存储单元里面又包含若干个 **存储元件**，每个存储元件可以存储一位二进制数 `0` 或 `1`；
		1. **存储单元（编址单位）**：由 **若干个存储元件** 组成，用于存放一串二进制代码（**存储字**），二进制代码位数为**存储字长**（$2^{n}$ /字节的偶数倍）；
		2. **存储元件**：用于存储 **一位** 二进制数据（`0`或`1`）的电子器件，**是存储器中最小的存储单位**；
		3. **存储字**：一个 **存储单元** 中存放的**二进制代码组合**；
		4. **存储字长**：一个 **存储字** 所包含的**二进制位数**（即该存储单元的存储元件个数）。
	2. **存储器地址寄存器（MAR）**：存放访存地址，经过地址译码后找到所选的存储单元，其位数反映**最多可寻址**的存储单元个数，**MAR 的长度与 PC 的长度** ==**相等**==；
	3. **存储器数据寄存器（MDR）**：用于暂存要从存储器读或写的信息，**位数通常等于存储字长**，一般为字节的2次幂的整数倍。
2. **辅助存储器（外存储器/外存）**：用于 **长期保存** 信息，容量大，速度慢，**断电后信息不丢失**。例：磁盘、固态硬盘。
3. **存储单元**：存储器被划分为若干个存储单元，单元中存放的是该地址对应的内容（指令或数据）。

#### （四） 运算器

完成算术运算和逻辑运算，是计算机的 **数据加工车间**。

| 部件          | 简称 | 功能说明                                 |
| --------------- | ------ | ---------------------------------------- |
| **算术逻辑单元**      | ALU    | 运算器的**核心计算部件**，执行具体的算术运算和逻辑运算。           |
| **通用寄存器**       |        |                                          |
| **累加器**         | ACC    | 暂存运算结果或操作数，是ALU工作时最常用的寄存器。               |
| **乘商寄存器**       | MQ     | 在乘除运算中**暂存乘数、商**，或配合ACC存放乘积的高/低位。        |
| **操作数寄存器**      | X（或GR） | **暂存操作数**，作为ALU的输入源之一。                   |
| **变址寄存器**       | IX     | 存放**变址值**，用于地址修改。                        |
| **基址寄存器**       | BR     | 存放**基地址**，用于地址重定位。                       |
| **程序状态（标志）寄存器** | PSW    | 存放运算过程中的**状态标志**（例：进位CF、溢出OF、为零ZF、符号SF）。 |

#### （五） 控制器

负责指挥协调计算机各部件自动工作，是计算机的 **神经中枢**。它从主存中逐条取出指令、分析指令（译码），然后发出相应的控制信号，指挥其他部件完成指令要求的操作。

1. **程序计数器（PC）**：用来存放 **下一条** 欲执行指令 **在主存中** 的 **地址**。**CPU** 自动将其内容加 1 （PC+1），即可自动形成下一条指令的地址，它与主存储器的 **MAR** 之间有一条直接通路；
2. **指令寄存器（IR）**：用来存放 **当前正在执行** 的指令，其内容来自于主存储器的 **MDR**。指令从主存读出后，会被暂存在 **IR** 中，随后其 **操作码OP(IR)** 会送入 **控制单元** 进行译码，而 **地址码Ad(IR)** 送往 **MAR**，用以取**操作数**；
3. **控制单元（CU）**：控制器的 **核心**，负责分析指令并产生一系列 **微操作命令序列**。接收 **IR** 送来的 **操作码** 和 **时序发生器** 送来的 **时序信号**，组合后生成**具体的控制信号**，用以控制。

#### （六） 流程

一般将运算器和控制器集成到同一个芯片上，称为 **中央处理器（CPU）**。**CPU** 和 **主存储器** 共同构成 **主机**，而除主机外的其他硬件装置（外存、I/O设备等）统称 **外部设备**，简称 **外设**。

如下图所示的冯 · 诺伊曼结构的模型机。**CPU** 包含 **算术逻辑单元(ALU)**、**通用寄存器组(GPRs)**、**标志寄存器(PSW)**、**控制器**、**指令寄存器(IR)**、**程序计数器(PC)**、**存储器地址寄存器(MAR)** 和 **存储器数据寄存器(MDR)**。

![650](image/1-计算机系统概述%20-%20计算机组成原理/冯诺依曼模型机.png)

**CPU** 和 **主存储器** 之间通过一组总线相连，总线中有 **地址**、**控制** 和 **数据** 三组信号线。

`MAR` 中的地址直接通过地址线找到要访问的存储单元，`控制线` 则发出读或写信号，决定数据的传送方向。

- **读操作**：主存把数据放到 `数据线` 上，`CPU` 再将数据从数据线接收到 `MDR` 中；
- **写操作**：`CPU` 直接将 `MDR` 里的 **数据** 送到 `数据线` 上，由 **主存** 写入。

## 1.3. 计算机软件和硬件的关系

### 1.3.1. 计算机软件

#### （一） 按功能分类

软件按照 **功能** 分类，可分为 **系统软件** 和 **应用软件**。

- **系统软件**：是一组保证计算机系统高效、正确运行的基础软件，通常作为系统资源提供给用户使用。例：操作系统(OS)、编译器、驱动程序、汇编器。
- **应用软件**：是为了满足用户特定需求而设计的软件。例：Word、浏览器、Photoshop。

#### （二） 按语言分类

软件按照 **语言** 分类，可分为**机器语言（二进制代码语言）**、**汇编语言**以及**语言软件（高级语言）**。

1. **机器语言（二进制代码语言）**：是计算机 ==**唯一**== 可以 **直接识别** 和 **执行** 的语言；
2. **汇编语言**：利用英文单词或其缩写 **代替** 二进制的指令代码，更容易人们记忆和理解（**必须** 经过 **汇编程序** 对其进行 **汇编/翻译**）；
3. **高级语言**：可以方便程序设计人员写出解决问题的处理方案和解题过程的程序。通常高级语言需要经过 **编译程序** 编译成 **汇编语言** 程序，然后经过 **汇编操作** 得到 **机器语言** 程序，或直接由高级语言程序 **翻译** 成机器语言程序。例：C、C++、Java。

**翻译程序：**

1. **汇编程序（汇编器）**：将汇编语言程序 **翻译** 成机器语言程序；
2. **解释程序（解释器）**：将源程序中的语句 **按执行顺序** 逐条 **翻译** 成机器指令并 **立即执行**；
3. **编译程序（编译器）**：将高级语言程序 **翻译** 成 **汇编语言** 或 **机器语言** 程序。

### 1.3.2. 软硬件的逻辑等价性

#### （一） 等价性

硬件实现的往往是最基本的算术和逻辑运算功能，而其他功能大多通过软件的扩充得以实现。  
而对某一功能来说，其即可由 **硬件实现**，又可由 **软件实现**，从用户的角度来看，它们在 **功能** 上是等价的—— **软/硬件逻辑功能的等价性**。例：浮点数运算即可用专门的浮点运算器硬件实现，又可通过一段子程序实现，二者功能上完全等价，不同的只是 **执行时间** 上，硬件实现 **优于** 软件实现的性能。

#### （二） 指令集体系结构（ISA）

**指令集体系结构（ISA）是软件与硬件之间的 接口/桥梁** ：
- 软件通过 `ISA` 来使用硬件资源；
- 硬件 **必须** 实现 `ISA` 中规定的 **所有** 指令与功能；
- `ISA` 是机器语言级程序员所能看到的 **计算机抽象模型**，是软件与硬件分工的 “分界线”。

**要点**：`ISA` 向下屏蔽了具体硬件实现的细节（微架构），向上为软件提供了统一的运行环境。只要 `ISA` 不变，同一份机器代码就能与运行在不同的硬件实现上。

### 1.3.3. 计算机系统的层次结构

计算机系统采用 **分层** 的思想进行组织，下层是上层的基础，上层是下层的功能扩展。同一功能既可以用硬件实现（下层），也可以用软件实现（上层），二者在逻辑功能上是等价的。

从 **软件/硬件交界面（ISA）** 出发，可以划分为 **虚拟机器** 和 **实际机器** 两个层次集合：

|    层次     | 名称             | 实现方式 | 说明                                                                             |
| :-----------: | :----------------- | :------- | :--------------------------------------------------------------------------------- |
|    **软件层**    |                    |          |                                                                                    |
|      第6层      | 应用层（虚拟机器）          | 应用软件     | 执行具体的应用程序（Word、浏览器）。                                                               |
|      第5层      | 高级语言层（虚拟机器）        | 编译器      | 运行C、Java等高级语言编写的程序。例：`y=a*b+c`                                                     |
|      第4层      | 汇编语言层（虚拟机器）        | 汇编器      | 用助记符编写程序，经汇编器转换为机器语言。例：`LOAD 5`                                                    |
|      第3层      | 操作系统层（虚拟机器）        | 操作系统     | 向上提供“广义指令”（系统调用接口），屏蔽硬件细节，管理资源。                                                    |
| **软硬件接口/分界线** |                    |          |                                                                                    |
|      第2层      | 指令集体系结构层（ISA/机器语言） | 软件与硬件的接口 | 机器语言级程序员看到的计算机，软硬件分界线。执行二进制机器指令。例：`000001 0000000101`取数指令；`000100 0000000110`乘法指令。 |
|    **硬件层**    |                    |          |                                                                                    |
|      第1层      | 微程序/微指令层（实际机器）     | 固件/硬件    | 由硬件直接执行微指令（微程序控制器）。例：微指令1、微指令2……                                                   |
|      第0层      | 数字逻辑层（实际机器）        | 硬件       | 门电路、寄存器、ALU等物理实现。                                                                  |
> **注意**：没必要过于纠结一个具体完整的结构，知道其分布情况即可。

## 1.4. 计算机系统的工作原理

### 1.4.1. “存储程序”工作方式

规定，程序执行前，需要将程序所含的指令和数据送入主存储器，一旦程序被启动执行，就无须操作人员的干预，自动 **逐条** 完成指令的取出和执行任务。

执行过程：`根据 PC 取指令` -> `指令译码，PC <- PC+1` -> `取操作数并执行` -> `送结果到存储器` -> `循环到第一步 PC 取指`。

取指令时，将 `PC` 的内容作为地址访问主存储器；在每条指令执行过程中，都需要计算吓一跳将执行指令的地址，并送至 `PC`。

若 **指令类型** 为：
1. **顺序型指令**：则下一条指令地址为 `PC` 的内容加上当前指令的长度；
2. **跳转型指令**：则下一条指令地址为指令中指定的目标地址。

当前指令执行完成后，根据 `PC` 的内容到主存储器中取出的是 **下一条将要执行的指令**，因而计算机能周而复始地自动取出并执行一条一条的指令。

### 1.4.2. 从源程序到可执行文件

在计算机中编写的 C 语言程序，都必须被转换为一系列的低级机器指令，这些指令按照 **可执行目标文件** 的格式打好包，并以 **二进制磁盘文件** 的形式存放起来。

![源程序转化过程|705](image/1-计算机系统概述%20-%20计算机组成原理/源程序转化过程.png)

翻译过程分为四个阶段：

1. **预处理阶段**：预处理器（cpp）对源程序中以字符 `#` 开头的命令进行处理，例：`#include` 命令后面的 `.h` 文件内容插入程序文件。输出结果是一个以 `.i` 为拓展名的源程序 `hello.i`。
2. **编译阶段**：编译器（ccl）对预处理后的源程序进行 **编译**，生成一个 **汇编语言** 源程序 `hello.s`。汇编语言源程序中的每条语句都以一种文本格式描述了一条 **低级机器语言指令**。
3. **汇编阶段**：汇编器（as）将 `hello.s` **翻译** 成 **机器语言** 指令，把这些指令打包成一个 **可重定位目标代码文件** `hello.o`。
4. **链接阶段**：链接器（ld）将多个可重定位目标代码文件和标准库函数合并为一个可执行目标文件，简称 **可执行文件**。

### 1.4.3. 指令执行过程的描述

可执行文件中的代码段是由一条一条机器指令构成的，指令是用 `0` 和 `1` 标志的一串 `0/1` 序列，用来指示 `CPU` 完成一个特定的原子操作。

| 阶段   | 操作                         | 说明                                                                                                                                             |
| -------- | ------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| **取指令**  | `PC → MAR → M → MDR → IR`      | **根据PC从内存取出指令送入IR。**将 `PC` 的内容送 `MAR`，`MAR` 中的内容直接送地址线，同时控制器将读信号送 **读/写信号线**，主存储器根据 **地址线** 上的地址和读信号，从指定存储单元读出指令，送到数据线上，MDR从数据线接收指令信息，并传送到 `IR` 中。 |
| **分析指令** | `OP(IR) → CU`                  | **指令译码并送出控制信号。**控制器根据 `IR` 中指令的 **操作码**，生成相应的 **控制信号**，送到不同的执行部件。                                                                                  |
| **执行指令** | `Ad(IR) → MAR → M → MDR → ACC` | **取数操作。**将 `IR` 中指令的地址码送 `MAR`，`MAR` 中的内容送 **地址线**，同时控制器将读信号送 **读/写信号线**，从主存储器中读出 **操作数**，并通过数据线送至 `MDR`，再传送到 `ACC` 中。                             |
| **准备下条** | `(PC) + 1 → PC`                | **计算下一条指令地址（顺序执行时）。**                                                                                                                              |
> **注意**：`(PC)` 指程序计数器 `PC` 中存放的内容。`PC → MAR` 应为 `(PC) → MAR`。**运算时不可省略。**

# 二、 计算机的性能指标

## 2.1. 机器字长

**机器字长（简称字长）**：指计算机进行一次整数运算所能处理的二进制数据位数，通常与 `CPU` 的寄存器位数、`ALU` 有关。它是 `CPU` 一次性能 **并行处理** 的二进制位数。常见位数：8位、16位、32位、64位。

**机器字长本质**：反映了 `CPU` **内部数据通路的宽度**。

| 概念         | 定义                  | 与机器字长的关系       |
| ---------- | :------------------ | :------------- |
| **指令字长**   | 一条指令的二进制位数          | 可能等于或为机器字长的整数倍 |
| **存储字长**   | 一个存储单元存放的二进制位数      | 通常等于机器字长       |
| **数据通路带宽** | CPU内部数据总线一次能并行传输的位数 | 通常等于机器字长       |
## 2.2. 数据通路带宽

**数据通路带宽**：指 **数据总线** 一次所能并行传送信息的位数。这里所说的数据通路宽度是指 ==**外部**==**数据总线的宽度**，它与CPU内部的数据总线宽度（内部寄存器的大小）有可能不同。

> **注意**：各个子系统通过数据总线连接形成的数据传送路径称为 **数据通路**。

## 2.3. 主存容量

主存容量：指主存储器所能存储信息的 **最大容量**，反映了计算机能 **直接访问** 的内存空间大小。

| 表示方式      | 示例           | 说明                 |
| --------- | ------------ | ------------------ |
| **字数×字长** | `512K × 16位` | 有512K个存储单元，每个单元16位 |
| **字节数**   | `1MB`、`4GB`  | 按字节编址时的总字节数        |

| 已知条件              | 公式                                | 示例                                     |
| ----------------- | --------------------------------- | -------------------------------------- |
| **MAR 位数、MDR 位数** | $主存容量=2^{MAR位数} × (MDR位数/8) 字节$   | MAR=16位，MDR=8位 -> $2^{16} × 8位 = 64KB$ |
| **地址线数、数据线数**     | $主存容量=2^{(地址线数)} × (数据线数 / 8) 字节$ | 地址线20根，数据线8根 -> $2^{20} × 1B = 1MB$    |

## 2.4. 运算速度

### 2.4.1. 吞吐量和响应时间

1. **吞吐量**：指系统在单位时间内处理请求的数量。系统吞吐量主要取决于 **主存储器** 的 **存取周期**。
2. **响应时间**：指从用户向计算机发送一个请求，到系统对该请求做出响应并获得所需结果的等待时间。通常包括 `CPU` 时间与等待时间。

### 2.4.2. CPU 时钟周期

1. **主频（CPU 时钟频率）**：机器内部主时钟的频率，即 **时钟周期的倒数**，它是衡量机器速度的重要参数。最直观理解是：每秒多少个时钟周期。
2. **CPU 时钟周期**：机器内部主时钟脉冲信号的宽度，它是 `CPU` 工作的 **最小时间单位**。
3. **时钟脉冲信号**：由机器脉冲源发出的脉冲信号经 **整形** 和 **分频** 后形成。
4. **时钟周期**：以相邻状态单元间组合逻辑电路的 **最大延迟时间** 为基准确定；也以指令流水线的每个流水段的最大延迟时间确定。

> **注意**：CPU 时钟周期=1/主频，主频通常以 Hz 为单位，10 Hz 表示每秒 10 个时钟周期。

### 2.4.3. CPI 与 IPC

**CPI**：指执行一条指令所需的时钟周期数。不同指令的时钟周期数可能不同，因此对于一个程序或一台机器来说，其 `CPI` 指该程序或该机器指令集中的所有指令执行所需的 `平均CPI`。

**IPS**：指每秒执行多少条指令。`IPS = 主频/平均 CPI`。

### 2.4.4. CPU 执行时间

**CPU 执行时间**：指运行一个程序所花费的时间。

$CPU执行时间 = 指令条数 × CPI × 时钟周期$ 

CPU 的性能（CPU 执行时间）取决于 **三个要素：主频、CPI 和指令条数**。

### 2.4.5. MIPS

**MIPS**：指 **每秒** 执行多少 **百万条** 指令。

$MIPS = 指令条数 / (执行时间 × 10^6) = 主频 / (CPI × 10^6)$ 

MIPS 对不同机器进行性能指标比较是有缺陷的，因为不同机器的指令集不同，指令功能也就不同。

### 2.4.6. FLOPS

**FLOPS**：指 **每秒** 执行多少次 **浮点运算**。

## 2.5. 基准程序

**基准程序**：是专门用来进行性能评价的一组程序，能够很好地反映机器在运行实际负载时的性能，可以通过在不同机器上运行相同的基准程序来比较在不同机器上的运行时间，从而评测其性能。
