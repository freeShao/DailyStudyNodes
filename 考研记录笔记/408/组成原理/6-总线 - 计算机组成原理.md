# 总线【\*非重点；※重点】

早期计算机的各部件之间通过单独的连线互连，该方式称为 **分散连接**。
随着I/O设备的种类和数量越来越多，为了**解决I/O设备与主机之间连接的灵活性**，设计了总线，计算机的结构从分散连接发展为 **总线连接**。

# 一、 总线概述

## 1.1. 总线的基本概念

**总线**：是一组能 **为多个部件分时和共享** 的 **公共信息传送线路**。
**特点**：
- **分时性**：同一时刻只允许有一个部件向总线 **发送** 信息；同一时刻只能有 **一个主设备** 控制总线的传输操作；
- **共享性**：总线上可以挂接多个部件。

**总线优缺点**：
- **优点**：
	- 便于增减外设；
	- 减少信息传输线的条数。
- **缺点**：降低了信息传输的并行性和信息的传输速度。

**总线设备**：按其对 **总线有无控制能力** 分为主设备和从设备。
- **主设备**：获得总线控制权的设备；
- **从设备**：被主设备访问的设备，它只能响应从主设备发来的各种总线命令。

**总线特性**：
- **机械特性**：尺寸，大小；
- **电气特性**：传输方向和有效电平范围；
- **功能特性**：每根传输线的功能；
- **时间特性**：信号和时序的关系。

## 1.2. 系统总线的分类

### 1.2.1. 按功能划分

#### （一） 片内总线

芯片内部的总线；
是 **CPU 芯片内部寄存器与寄存器之间、寄存器与ALU之间** 的公共连接线。

#### （二） 系统总线

计算机系统内 **各功能部件(CPU、主存、I/O接口)之间相互连接** 的总线；
按 **系统总线传输内容** 的不同分为三类：
1. **数据总线**：
	- 传输各功能部件之间的数据信息；
	- 是 **双向传输线**，其位数与机器字长、存储字长有关。
2. **地址总线**：
	- 指出主存和I/O设备接口电路的地址；
	- 是 **单向传输线**；
	- 地址总线的位数与主存地址空间的大小有关。
3. **控制总线**：
	- 传输控制信息；
	- 包括控制命令和反馈信号。
> **注意**：
> 1. 命令：是控制总线上的 **控制信号**，是“做什么”的 **控制意图**；
> 2. 指令：是主存中存储的 **机器码**，是“怎么做”的 **操作描述**。

![555](image/6-总线%20-%20计算机组成原理/系统总线.png)

#### （三） I/O总线

主要用于连接中低速的I/O设备；
通过I/O接口与系统总线相连接；
目的是将低俗设备和高速总线分离，以提升总线的系统性能；
常见的有 **USB、PCI总线**。

> **USB**：通用 **串行总线**。
> **即插即用，热插拔，有很强的连接能力，有很好的可拓展性，高速传输**。

#### （四） 通信总线

是在计算机系统之间或计算机系统或其他系统之间传送信息的总线；
通信总线也称 **外部总线**。

### 1.2.2. 按时序控制方式分

#### （一） 同步总线

总线上连接的部件或设备 **通过统一的时钟进行同步**，在规定的时钟节拍内进行规定的总线操作，来完成部件或设备之间的信息传输。

#### （二） 异步总线

总线上连接的部件或设备 **没有统一的时钟**，而以信号握手的方式来协调各部件或设备之间的信息传输，总线操作时序不是固定的。

### 1.2.3. 按数据传输格式分

#### （一） 串行总线

只有一条双向传输或两条单向传输的数据线，**数据按比特位串行顺序传输**，其效率低于并行总线。
串行传输对数据线的要求不高，**适合长距离通信**。

![555](image/6-总线%20-%20计算机组成原理/串行总线.png)

#### （二） 并行总线

有多条双向传输的数据线，**可以实现多比特位的同时传输**，其效率比串行总线更高。
**缺点**：各条数据线的传输特点可能存在一些差异，数据线之间互相干扰会造成传输错误，因此 **并行总线适合近距离通信**。

> **注意**：并行总线并不一定总比串行总线快。
> 串行总线可以提升工作频率来提高传输速度，而并行总线因为数据协调性等问题无法持续提高工作频率。

## 1.3. 总线的结构

|         | 单总线结构                                          | 双总线结构                                                 | 三总线结构                                            |

| **缺点**  | 1.带宽低，负载重；<br>2.多个部件只能争用唯一的主线；<br>3.不支持并发传送操作。 | 需要增加通道等硬件设备。                                          | **任意时刻只能使用一种总线**，系统工作效率低。                        |

## 1.4. 总线的性能指标

| 指标             | 描述                                                                                 |
| -------------- | :--------------------------------------------------------------------------------- |
| **传输周期**       | 指一次总线操作所需的时间，由若干总线时钟周期构成                                                           |
| **时钟周期**       | 即机器的时钟周期                                                                           |
| ==**工作频率**==   | 总线上各种操作的频率，为总线周期的倒数<br>$工作频率 = \frac{1}{总线周期}$                                     |
| **时钟频率**       | $时钟频率 = \frac{1}{时钟周期}$                                                            |
| ==**宽度(位宽)**== | 总线上能同时传输的数据位数，通常指数据总线的根数                                                           |
| ==**带宽**==     | 总线的最大数据传输率，即 **单位时间内总线上最多可传输数据的位数**<br>$总线带宽 = 总线工作频率 \times (总线位宽 / 8)$ 【单位：字节/s】 |
| **总线复用**       | 1.一种信号线在不同的时间传输不同的信息；<br>2.可以使用**较少的线传输更多的信息**，从而节约空间和成本。                          |
| **信号线数**       | 地址总线、数据总线和控制总线，3种总线数的综合称为信号线数                                                      |
|                | **重要关系**：$总线带宽(传输率) = 总线宽度 \times 总线工作频率$                                          |

# 二、 总线事务与定时

## 2.1. 总线事务的基本概念

**从请求总线到完成总线使用的操作序列，称为总线事务**，它是在一个总线周期中发生的一系列活动。

**总线事务过程**：

| 事务阶段     | 操作                                          |
| :------- | :------------------------------------------ |
| **请求阶段** | 主设备发出总线传输请求，并且获得总线控制权                       |
| **仲裁阶段** | 总线仲裁机构决定将下一个传输周期的总线使用权授予某个申请者               |
| **寻址阶段** | 主设备通过总线给出要访问的从设备地址及有关命令，启动从模块               |
| **传输阶段** | 主模块和从模块进行数据交换，可单向或双向进行数据传送(*一般只能传输一个字长的数据*) |
| **释放阶段** | 主模块的有关信息均从系统总线上撤出，让出总线使用权。                  |

## 2.2. 数据传送方式

### 2.2.1. 非突发传送方式

在 **每个传送周期内都线传送地址，再传送数据**，每次只能传输一个数据。
![350](image/6-总线%20-%20计算机组成原理/非突发传送方式.png)

### 2.2.2. 突发传送方式：
==【常考】==

- 突发传送方式是指发送方在传输完成地址后，**连续进行若干次数据的发送**，即一次传输**一个地址**和**一批连续的数据**；
- 突发传送方式能够进行**连续成组数据的传送**，其寻址阶段发送的是连续数据单元的首地址；
- 突发传送方式**可以提高总线数据传输率**；
- 主设备只需给出一个首地址，从设备就能从首地址开始的若干连续单元读出或写入多个数据。

## 2.3. 总线定时

具体总线事务的每一个步骤、总线上的每一个信号、何时开始、何时结束就是总线的定时问题。【实质上是一种协议或者规则】

### 2.3.1. 同步/异步定时方式

|     | 同步定时/控制方式                                                                                                      | 异步定时/控制方式                                                                                                                       |
| --- | :------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| 定义  | 1.由**统一时序控制**的通信方式；<br>2.同步通信采用 **公共时钟、有统一的时钟周期，同步时钟信号不由各设备提供**；<br>3.同步控制既可以 **用于CPU控制，又可用于高速的外部设备控制**。       | 1.没有统一的时钟，没有固定的时间间隔(不采用时钟信号，只采用握手)；<br>2.**完全依赖传送双方互相制约的“握手”信号来实现定时控制**；<br>3.传送操作是由双方按需求分配时间的；<br>4.每次握手完成一次通信，但是一次通信往往交换多位数据。 |
| 优点  | 1.传送 **速度快**，具有较高的传输速率；<br>2.总线控制逻辑简单；<br>3.**不需要应答信息，且总线长度短**；<br>4.**用一个公共的时钟信号进行同步**；<br>5.**各部件的存取时间较接近**。 | 1.**总线周期长度可变**；<br>2.能保证两个工作速度相差很大的部件或设备之间可靠地进行信息交换；<br>3.自动适应时间的配合。                                                            |
| 缺点  | 1.主从设备属于强制性同步；<br>2.不能及时进行数据通信的有效性验证；<br>3.可靠性较差。                                                              | 比同步稍复杂，速度比同步方式慢。                                                                                                                |
| 适用于 | 适用于**总线长度较短**及**总线所接部件的存储时间比较接近的系统**；<br>采用同步控制也可以进行数据的传输，但不能发挥快速设备的高速性能。                                      | 主要用于在**不同的设备**之间进行通信。                                                                                                           |

### 2.3.2. 异步定时方式分类

![555](image/6-总线%20-%20计算机组成原理/信号互锁.png)

|                | 本质                                                                                                                             |
|:-------------- |:-------------------------------------------------------------------------------------------------------------------------------- |
| **不互锁方式** | 主设备发请求->**不必**等从设备的回答，才能撤销“请求信号”【*速度最快*】                                                           |
| **半互锁方式** | 主设备发请求->**需要**等从设备的回答，才能撤销“请求信号”<br>从设备收到回答->**不必**等到主设备的“请求信号”撤销，才撤销“回答信号” |
| **全互锁方式** | 主设备发请求->**需要**等从设备的回答，才能撤销“请求信号”<br>从设备收到回答->**需要**等到主设备的“请求信号”撤销，才撤销“回答信号” |

### 2.3.3. 半同步定时方式

在 **异步总线中引入时钟信号**，这种方式就是 **半同步定时方式**。

![555](image/6-总线%20-%20计算机组成原理/半同步方式的时序图.png)

在同步存储器读时序的基础上 **引入了一个等待信号Wait**，表示存储器还没有准备好数据：
1. 存储器在接收到主设备的读请求后，**如果还没有准备好数据**，则将Wait信号置位，**插入等待周期**，让主设备等待；
2. **当数据准备好并发送到数据总线时**，存储器 **撤销Wait信号**，主设备检测到Wait信号消失时，取走数据总线上的数据。
> **注意**：这种方式主设备的 **等待时间不固定**，**由从设备自身情况决定**。

**优点**：控制方式比异步定时简单，可靠性高。
**缺点**：系统时钟频率不能太高，整体上看，系统的工作速度不高。
> **注意**：“等待周期”以整个时钟周期为单位，而**慢速设备需要多个等待周期**，将严重**拖慢高速设备的总线占用时间**，导致系统整体效率下降。
