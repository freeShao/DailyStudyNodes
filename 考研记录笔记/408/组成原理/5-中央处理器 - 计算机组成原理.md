# 一、 CPU的功能和基本结构

## 1.1. CPU的功能

- 指令控制：
	- 完成取指令、分析指令和执行指令的操作，即程序的顺序控制。
- 操作控制：
	- 管理闭关产生由内存取出的每条指令的操作信号；
	- 把各种操作信号送往相应的部件，从而控制这些部件按指令的要求进行动作。
- 时间控制：
	- 对各种操作进行时间上的控制。
- 数据加工：
	- 对数据进行算术和逻辑运算。
- 中断处理：
	- 对计算机运行过程中出现的异常情况和特殊请求进行处理。

## 1.2. CPU的基本结构

**CPU = 运算器 + 控制器**

### 1.2.1. CPU寄存器的分类

#### （一） 用户可见的寄存器

用户可对这类寄存器 **编程**。
> **如：通用寄存器，PSW，基址寄存器(用于实现多道程序设计或者编制浮动程序)，状态/标志寄存器。**

#### （二） 用户不可见的寄存器

**特点**：
- 对用户透明；
- 保留各种状态信息(*溢出标志OF、符号标志SF、零标志ZF、进位标志CF*);
- PSW中的这些位参与并决定微操作的形成；
- 不可对这类寄存器编程。
> **如：MAR、MDR、IR、微程序控制器CM。**


### 1.2.2. CPU易混淆点

**转移指令**时：需要判别转移是否成功。若成功则PC修改为转移指令的目标地址；否则下一条指令的地址仍然是PC自增后的地址。
**计算机分两大部分**：**控制部件和执行部件**
- 控制器就是控制部件。(指令寄存器、操作控制器、程序计数器都是控制部件)
- 运算器、存储器、外围设备就是执行部件。
**各寄存器的位数等于什么？**【和 *地址* 有关的就取决于机器字长；和 *数据大小*  有关的就取决于容量】

| 通用寄存器 | PC    | IR   | MAR  | MDR         |
| ----- | ----- | ---- | ---- | ----------- |
| 机器字长  | 存储器容量 | 指令字长 | 指令字长 | 机器字长=CPU的位数 |

## 1.3. 指令执行过程

### 1.3.1. 指令周期
- 指令周期的基本概念
- 指令周期、CPU周期、时钟周期的关系
- 不同指令的指令周期差异

### 1.3.2. 指令执行步骤

## 1.4. 数据通路的功能和基本结构

### 1.4.1. 数据通路的基本概念
- 数据通路：指令执行过程中数据流经的路径
- 数据通路由**组合逻辑单元 + 时序逻辑单元**组成

### 1.4.2. 数据通路的基本结构
- **单总线结构**：简单、冲突多、性能低
- **多总线结构**：复杂、冲突少、性能高

### 1.4.3. 数据通路中的数据流动
- 取指阶段的数据通路
- 执行阶段的数据通路（如加法、访存、转移等）
- **控制信号**的作用：选择数据来源、控制操作类型


## 1.5. 控制器的功能和工作原理

### 1.5.1. 控制器的基本功能
- 指令译码
- 产生控制信号
- 时序控制

### 1.5.2. 控制器的主要类型
- **硬布线控制器**
  - 组合逻辑实现
  - 速度快、复杂、不易修改
- **微程序控制器**
  - 微指令/微程序实现
  - 灵活、易修改、速度较慢

### 1.5.3. 微程序控制器基本概念
- 微命令、微操作、微指令、微程序
- 控制存储器（CM）、微地址寄存器
- 微指令的格式与编码方式


## 1.6. 异常和中断机制

### 1.6.1. 异常和中断的基本概念※
- 中断：外部事件引起（异步）
- 异常：指令执行引起（同步）
- **区别**：来源、发生时机、返回方式

### 1.6.2. 异常和中断的分类※
- **中断**（可屏蔽/不可屏蔽）
- **陷阱**（Trap）：主动触发（如系统调用）
- **故障**（Fault）：可修复错误（如缺页异常）
- **终止**（Abort）：严重错误，不返回

### 1.6.3. 异常和中断的检测与响应
- 中断响应流程
- 中断向量表
- 中断处理过程：保护现场 → 执行服务程序 → 恢复现场 → 返回
- 多重中断与中断屏蔽


## 1.7. 指令流水线

### 1.7.1. 指令流水线的基本概念※
- 流水线原理：指令重叠执行
- 流水线深度（级数）
- 吞吐率与加速比

### 1.7.2. 指令流水线的基本实现
- 经典五级流水线：IF → ID → EX → MEM → WB
- 流水线寄存器的作用
- 流水线时空图

### 1.7.3. 冒险（Hazard）的处理
- **结构冒险**：硬件资源冲突 → 资源分离 / 插入停顿
- **数据冒险**：数据依赖 → 转发（前推）/ 插入气泡 / 编译器调度
- **控制冒险**：转移指令 → 分支预测 / 延迟槽

### 1.7.4. 超标量和动态流水线的基本概念※
- **超标量**：多条指令并行发射
- **动态流水线**：支持乱序执行
- 顺序执行与乱序执行


## 1.8. 多处理器基本概念

### 1.8.1. SISD、SIMD、MIMD、向量处理器
- **SISD**：单指令单数据流（传统CPU）
- **SIMD**：单指令多数据流（向量处理器、GPU）
- **MIMD**：多指令多数据流（多核CPU、集群）
- **向量处理器**：一次处理一维数组

### 1.8.2. 硬件多线程
- 细粒度交替
- 粗粒度交替
- 同时多线程（SMT，如Intel超线程）

### 1.8.3. 多核处理器（multi-core）
- 单芯片集成多个处理核心
- 共享/私有Cache结构
- 核间通信方式

### 1.8.4. 共享内存多处理器（SMP）
- 多个处理器共享同一物理内存
- UMA（统一内存访问）与NUMA（非统一内存访问）
- 缓存一致性协议（如MESI）
