顺序栈：采用顺序存储结构的栈称为顺序栈，利用一组地址的连续存储单元存放自栈底到栈顶的数据元素，同时附设一个指针(top)指示当前栈顶元素的位置。 ^7gjk8Pu1

栈的基本概念 ^hYbe2kDn

栈的基本操作 ^tjPemCHL

StackEmpty (S)：判断一个栈是否为空，若栈S为空则返回true；否则返回false。 ^65BuGHMI

Push (&S, x)：进栈，若栈S未满，则将x加入使之成为新栈顶。
Pop (&S, &x)：出栈，若栈S非空，则弹出栈顶元素，并用x返回。 ^nb2cZy5D

InitStack (&S)：初始化一个空栈S。 ^YljQU99r

定义：只允许在一端进行插入或删除操作的线性表。 [先进后出] ^RBWwCSEl

结构 ^yK80W9Oi

栈顶（Top）：线性表允许进行插入删除的那一端。
栈顶（Bottom）：固定的，不允许进行插入和删除的另一端。 ^Tocun2yd

GetTop (S, &x)：读栈顶元素，若栈S非空，则用x返回栈顶元素。 ^6HuyMRj1

DestoryStack (&S)：销毁栈，并释放栈S占用的存储空间 (”&“ 表示引用调用)。 ^GjFhgVil

卡特兰数：n个不同元素进栈，出栈元素不同排列组合的个数为： ^7ZxkdHeu

算法题中，如果题干没有做出限制，这些均可作为基本的操作函数使用 ^Ao6hfDTb

基本结构与操作 ^Kq704qxg

栈顶指针：S.top，初始时设置 S.top=-1 。 ^8pr8iCK4

栈顶元素：S.data[S.top] 。 ^fLETJeOM

进栈操作：栈不满时，栈顶指针先加1，再送值到栈顶元素。 ^4h6LuDDz

出栈操作：栈非空时，先取栈顶元素值，再送栈顶指针减1。 ^MuEcxCaz

栈空条件：S.top == -1 。 ^RdgwdYkb

栈满条件：S.top == MaxSize - 1；栈长：S.top + 1 。 ^6euZwlyd

让两个顺序栈共享一个一维数组空间，将两个栈的栈底分别设置在共享空间的两端，两个栈顶向共享空间的中间延伸。
本质是在避免 [上溢] 的前提下，节省存储空间。 ^0GlFXLOm

基本原则 ^2TiNLKB0

当两个栈的栈顶指针都指向栈顶元素，top=-1时0号栈为空，top1=MaxSize时1号栈为空。 ^BgAi5wRy

当两个栈顶指针相邻(top1 - top0 = 1)时，判断为栈满。 ^630GqdAX

当0号进栈时top0先加1，再赋值，1号栈进栈时，top1先减1再赋值；出栈时则刚好相反。 ^CDm1itcz

存取数据的时间复杂度均为 O(1) ^p2ejWD7U

采用单链表实现，并规定所有操作都是在单链表的表头进行。 ^cy9ahv6t

优点：
便于多个栈共享存储空间和提高其效率；
且不存在栈满上溢的情况。 ^fCb779C6

先序序列含n个不同元素时，能够确定多少种不同的二叉树。 ^v4se63HV
