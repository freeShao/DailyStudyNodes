# 结构体定义

## 1. 顺序表

```cpp
define maxsize 50
typedef struct {
    int data[maxsize];
    int length;
} SqList;
int *arr = (int*)malloc(10*sizeof(int)); // 申请整型空间（可更换为char）
// 一般用于链表需要额外数组空间辅助
// 一般使用方法：
void func(int a[], int n){
    // a[] 表示传入数组，n可以代指a[]的长度/其他相关变量(循环次数等)
    return; // [*]void 下不可返回任何值
}
```

## 2. 单链表（带头结点）[* 可能考手写结构体]

```cpp
typedef int ElemType;
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
// 单个结点
LNode *p = HEAD->next; // HEAD为函数输入链表的头结点，如下
// 一般使用方法：
void func(LinkList L){ // L 代指头结点
    LNode *p = L->next;
    return;
}
```

## 3. 栈与队列

### 3.1. 顺序栈

```cpp
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];
    int top; // 指向栈顶元素下标，初值-1
} SqStack;
```

### 3.2. 循环队列

```cpp
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];
    int front, rear; // front 指向队头，rear 指向队尾下一个位置
} SqQueue;
```

## 4. 二叉树

```cpp
typedef int ElemType;
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

## 5. 图

### 5.1. 邻接矩阵

```cpp
#define MaxVertexNum 100
typedef char VertexType;
typedef int ArcsType;

typedef struct {
    VertexType vexs[MaxVertexNum];
    ArcsType arcs[MaxVertexNum][MaxVertexNum];
    int vexnum, arcnum;
} MGraph;
```

### 5.2. 邻接表

```cpp
typedef struct ArcNode {
    int adjvex;
    struct ArcNode *nextarc;
    // int weight;
} ArcNode;

typedef struct VNode {
    VertexType data;
    ArcNode *firstarc;
} VNode, AdjList[MaxVertexNum];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
```
