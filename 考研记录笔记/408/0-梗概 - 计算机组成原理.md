## 1.1. 星级评分核心逻辑说明

### 1.1.1. 五星（⭐⭐⭐⭐⭐）—— 必拿分考点，必须烂熟于心

这些是每年必考、分值最高的核心内容，通常占计组总分值的60%以上：

| 考点              | 考查频率 | 典型题型    |
| --------------- | ---- | ------- |
| 补码表示与运算（含溢出判断）  | 每年   | 选择题+综合题 |
| IEEE754浮点数标准    | 每年   | 选择题+综合题 |
| Cache-主存映射方式与计算 | 每年   | 选择题+综合题 |
| 指令流水线（冒险与解决）    | 高频   | 选择题+综合题 |
| 指令格式与寻址方式       | 高频   | 选择题+综合题 |
| 数据通路与控制器的设计     | 中频   | 综合题     |

### 1.1.2. 四星（⭐⭐⭐⭐）—— 高分保障，需熟练

这些是次高频考点，掌握后能显著拉开分数差距：

| 考点                | 考查频率 | 说明       |
| ----------------- | ---- | -------- |
| 性能指标计算（CPI、执行时间等） | 每年   | 第一章最重要内容 |
| 定点数移位运算           | 中频   | 补码移位规则易错 |
| 主存与CPU连接          | 中频   | 片选与地址译码  |
| Cache写策略          | 中频   | 写直达/写回区别 |
| 中断方式与DMA方式        | 中频   | 与OS结合考查  |

### 1.1.3. 三星（⭐⭐⭐）—— 基础得分，理解即可

这些是基础概念，选择题常考，理解原理即可：

| 考点             | 说明         |
| -------------- | ---------- |
| 冯·诺依曼结构        | 五大部件、存储程序  |
| 翻译程序（汇编/编译/解释） | 区分三种翻译器    |
| 浮点数加减运算        | 对阶、尾数规格化   |
| CISC与RISC对比    | RISC特征     |
| 指令周期           | 不同阶段的数据流   |
| 总线仲裁与定时        | 集中仲裁方式     |
| 程序查询/中断/DMA    | I/O方式的基本原理 |

### 1.1.4. 二星及以下（⭐⭐ / ⭐）—— 了解概念，不需深究

这些低频考点，记住关键结论即可：

| 考点          | 核心记忆点                 |
| ----------- | --------------------- |
| 计算机发展历程     | 电子管→晶体管→集成电路→大规模集成电路  |
| Amdahl定律    | 加速比 = 改进后性能/改进前性能     |
| 虚拟存储器（计组部分） | 页表、地址转换由OS重点讲         |
| 异常和中断分类     | 内中断/外中断概念             |
| 多处理器概念      | SISD/SIMD/MISD/MIMD定义 |
| 总线标准        | 知道PCI、USB等名称即可        |
