# 数据的表示和运算

# 一、 数制与编码

## 1.1. 进位计数制及其相互转换

在计算机系统内部，所有信息都是用 **二进制** 进行编码的。

1. 二进制只有两种状态，使用有两个稳定状态的物理器件就可以表示二进制数的每一位，制造成本比较低；
2. 二进制位 `0` 和 `1` 正好与逻辑值“真”和“假”相对应，为计算机实现逻辑运算和程序中的逻辑判断提供了便利条件。
3. 二进制的编码和运算规则很简单，通过逻辑门电路能方便实现算术运算。

| **运算类型**     | **常见文字描述**      | **C语言符号** | **真值表核心**  |
| ------------ | --------------- | --------- | ---------- |
| **与 (AND)**  | 两位同时为1时结果为1     | `&`       | 1 & 1 = 1  |
| **或 (OR)**   | 两位中至少有一个为1时结果为1 | `\|`      | 1 \| 0 = 1 |
| **异或 (XOR)** | 两位不同时结果为1       | `^`       | 1 ^ 0 = 1  |
| **取反 (NOT)** | 将位0变1，1变0       | `~`       | ~1 = 0     |

### 1.1.1. 进位计数制

常用的进位计数制有 `十进制`、`二进制`、`八进制`、`十六进制`等。十进制是日常生活中最常使用的，而计算机中通常使用二进制数、八进制数和十六进制数。

在进位计数制中，每个 **数位** 所用到的不同 **数码** 的个数称为 **基数**。十进制(D)的基数为 10（0~9），每个数位计满 10 就向高位进位，即“逢十进一”。  
每个数码所表示的数值 **等于** 该数码本身乘以一个与它所在数位有关的常数，这个常数成为 **位权**。一个进位数的数值大小就是它的各位数码 **按权相加**。

一个 `r 进制数`（ $K_nK_{n-1}…K_0K_{-1}…K_m$ ）的数值可表示为：$K_nr^n+K_{n-1}r^{n-1}+···+K_0r^0+K_{-1}r^{-1}+···+K_{-m}r^{-m}=\sum_{i=n}^{-m}K_ir^i$。$r$ 是基数；$r^i$ 是第 $i$ 位置的位权；$K_i$ 的取值可以是 0, 1,···, r-1 共 r 个数码中的任意一个。

1. **二进制(B)：** 基数为 2，使用 0 和 1 两个数码，逢二进一。它的任意数位的权为 $2^i$, $i$ 为所在位数。计算机内部所有信息均采用二进制编码。
2. **八进制(O/Q)：** 基数为 8，使用`0~7`共 8 个数码，逢八进一。**1 位八进制对应 3 位二进制**。常用于早期计算机系统或 Unix 文件权限表示，作为二进制的一种 **紧凑书写形式**。
3. **十六进制(H)：** 基数为 16，使用`0~9`和`A~F`共 16 个数码，逢十六进一。**1 位十六进制对应 4 位二进制**。是现代计算机中最常用的 **二进制书写替代形式**，广泛用于内存地址、机器指令、调试信息等场景。

### 1.1.2. 不同进制数之间的相互转换
#408/组成原理/二进制运算/1-进制转换

#### （一） 二进制 -> 十进制

方法：按权展开求和。将每个数位上的数码乘以该位的位权，再求和。

示例：$1011. 01B=1 \times2 ^{3}+0 \times2 ^{2}+1 \times2 ^{1}+1 \times2 ^{0}+0 \times2 ^{-1}+1 \times2 ^{-2}=8+0+2+1+0+0.25=11.25$

#### （二） 十进制 -> 二进制、八进制、十六进制

- **整数部分：** **除基取余法**。用基数不断去除十进制整数，取余数作为该位数字，直到商为0。最后取的余数是最高位（倒序排列）。
- **小数部分：** **乘基取整法**。用基数不断乘十进制小数，取整数部分作为该位数字，直到小数部分为0或达到精度要求。先取的整数是最高位（正序排列）。

示例：$123.6875 D = 1111011.1011 B$

> **注意：** 并不是所有十进制小数都可用二进制小数表示，如 `0.3`。但任意一个二进制小数都可以用十进制小数精确表示。

#### （三） 二进制 <-> 八进制/十六进制

以小数点为界，分别对整数部分和小数部分进行分组转换。

| **转换类型**            | **分组位数** | **整数部分（小数点向左）**       | **小数部分（小数点向右）**       |
| ------------------- | -------- | --------------------- | --------------------- |
| **二进制 ->** **八进制**  | `3`位一组   | 从右向左分组，最左边不足`3`位时补`0` | 从左向右分组，最右边不足`3`位时补`0` |
| **二进制 ->** **十六进制** | `4`位一组   | 从右向左分组，最左边不足`4`位时补`0` | 从左向右分组，最右边不足`4`位时补`0` |

反向转换：每位八进制（或十六进制）数码转换为对应的3位（或4位）二进制数。

## 1.2. 定点数的编码表示

### 1.2.1. 基本概念

**真值：** 带有`+`或`-`符号的数。真值是机器数所代表的实际值。

**机器数：** 数字在计算机中的二进制表示形式（`0`正，`1`负。如 `0,101->+5`，`,`用以区分符号位与数值位），其位数通常受机器字长的限制。**真值是人用的，机器数是机器用的**。

**定点数**：小数点的位置固定不变的数。根据小数点位置的不同，可分为 **定点整数** 和 **定点小数**。

- **定点整数**：小数点固定在数值最低位之后，表示 **纯整数**。
- **定点小数**：小数点固定在符号位之后、数值最高位之前，表示 **纯小数**。

| **真值**   | **原码**    | **反码**    | **补码**    | **移码**    |
| -------- | --------- | --------- | --------- | --------- |
| **+127** | 0111 1111 | 0111 1111 | 0111 1111 | 1111 1111 |
| **+5**   | 0000 0101 | 0000 0101 | 0000 0101 | 1000 0101 |
| **+0**   | 0000 0000 | 0000 0000 | 0000 0000 | 1000 0000 |
| **-0**   | 1000 0000 | 1111 1111 | 0000 0000 | 1000 0000 |
| **-5**   | 1000 0101 | 1111 1010 | 1111 1011 | 0111 1011 |
| **-127** | 1111 1111 | 1000 0000 | 1000 0001 | 0000 0001 |
| **-128** | 无法表示      | 无法表示      | 1000 0000 | 0000 0000 |

### 1.2.2. 移码

#### （一） 原码表示法

- 符号位：`0`表示`正`，`1`表示`负`
- 数值位：与真值的绝对值相同
- 表示范围：$-(2^n - 1) \sim + (2^n - 1)$ ，八位二进制码表示范围 $-127 \sim 127$
- 缺点：0的表示不唯一（`-0: 1000 0000` 和 `+0: 0000 0000`）

#### （二） 反码表示法

- 正数：反码与原码相同
- 负数：符号位不变，数值位按位取反
- 表示范围：$-(2^n - 1) \sim + (2^n - 1)$ ，八位二进制码表示范围 $-127 \sim 127$
- 缺点：0的表示不唯一。`-0: 1111 1111` 或 `+0: 0000 0000`

#### （三） 补码表示法

- 正数：补码与原码相同
- 负数：补码 = 反码 + 1（末位加1）
- 表示范围：$-2^n \sim + (2^n - 1)$ ，八位二进制码表示范围 $-128 \sim 127$
- 优点：`0`的表示唯一，加减运算统一，比原、反码多表示一个最小负数

#### （四） 移码表示法

- 移码 = 真值 + 偏移量（通常为 $2^{n-1}$）= 补码符号位取反
- 用于表示浮点数的 **阶码**
- 便于比较两个浮点数的大小

### 1.2.3. 定点数的移位运算

细节可看： [2.2.1. 移位运算](2-数据的表示和运算%20-%20计算机组成原理.md#2.2.1.%20移位运算)

- **算术移位**：保持符号位不变，数值位进行移位。左移相当于乘`2`，右移相当于除`2`。
- **逻辑移位**：不考虑符号位，所有位统一移位，用`0`填充空位。
- **循环移位**：移出的位补到另一端。

### 1.2.4. 定点数的溢出判断

- **判断方法**：比较两个加数的符号与和的符号
- 正+正=负 -> 上溢
- 负+负=正 -> 下溢
- 采用双符号位（**变形补码**）可判断溢出：`01`表示上溢，`10`表示下溢

> **变形补码** \*：双符号位的补码表示，也称模4补码。左符表示真正的 **符号位**，右符用于判断 **溢出**。本质是 **模运算** 的原理。

## 1.3. 整数的表示

### 1.3.1. 无符号整数的表示

当一个编码的全部二进制位 **均为数值位**，而 **没有符号位** 时，该编码表示的就是无符号整数。无符号整数常用于表示地址、指针、长度等非负整数。在 C 语言中，使用 `unsigned` 关键字修饰的整数类型即为无符号整数（如 `unsigned int`）。

- **特点**：所有位都参与数值运算，没有符号位。
- **表示范围**：对于 $n$ 位无符号整数，表示范围为 $0 \sim 2^n - 1$。
- **运算规则**：采用正常的二进制加法，当最高位产生进位时，表示结果超出了表示范围，此时进位标志位 $CF$ 置 `1`。

### 1.3.2. 有符号整数的表示

将符号数值化，并将符号位放在有效数字的前面，就组成了有符号整数。在 C 语言中，默认的 `int`、`short`、`long` 等均为有符号整数类型。

- **特点**：最高位为符号位（`0` 表示正，`1` 表示负），其余位为数值位。
- **编码方式**：主要有三种——原码、反码和补码。现代计算机普遍采用 **补码** 表示有符号整数。

- **原码**：符号位+真值的绝对值。优点是直观易懂，缺点是`0`的表示不唯一（`+0`:`0000` 和 `-0`:`1000`），且加减运算复杂。
- **反码**：正数的反码与原码相同；负数的反码是原码符号位不变，数值位按位取反。通常作为原码到补码的中间过渡。
- **补码**：正数的补码与原码相同；负数的补码是其反码末位加 `1`（即“取反加一”）。补码的优点是将减法统一为加法运算，且`0`的表示唯一 `0000`。

- **表示范围**：对于`n`位有符号整数（补码），表示范围为 $-2^{n-1} \sim (+2^{n-1} - 1)$。

### 1.4.1. 整数类型概览

| **类型**     | **关键字**               | **常见位数（32位环境）** | **表示范围（补码）**              |
| ---------- | --------------------- | --------------- | ------------------------- |
| **短整型**    | `short` / `short int` | 16 位            | $-32768 \sim 32767$       |

### 1.4.2. 有符号数和无符号数的转换

强制类型转换的结果保持位置不变，仅改变了解释这些位的方式。

```c
int main()
{
    // 例子1: short(有符号) → unsigned short(无符号)
    // x的16位补码: 1110 1111 0001 1111
    short x = -4321;
    // 位模式不变，解释为无符号: 1110 1111 0001 1111  对应真值: 61215
    unsigned short y = (unsigned short)x;
    // 输出结果: x=-4321, y=61215
    printf("x=%d, y=%u\n", x, y);
 // %u 表示按 unsigned int 格式输出或输入数据
    
    // 例子2: unsigned short(无符号) → short(有符号)
    // x2的16位: 1111 1111 1111 1111  对应真值: 65535
    unsigned short x2 = 65535;
    // 位模式不变，解释为补码: 1111 1111 1111 1111
    short y2 = (short)x2;
 // 输出结果: x2=65535, y2=-1
    printf("x2=%u, y2=%d\n", x2, y2);
    return 0;
}
```

### 1.4.3. 不同字长整数之间的转换

#### （一） 当大字长变量向小字长变量强制类型转换时

系统把多余的高位部分直接截断，低位直接赋值

#### （二） 短字长整数到长字长整数的转换时

要保持数值不变，需要对高位部分进行填充：

- 原数为**无符号整数**，高位填充 **0**（零扩展）
- 原数为**有符号整数**，高位填充**符号位**（符号扩展）

> **注意**：`char` 的类型取决于编译器实现，默认通常为 **有符号**（`signed char`），
> 此时转换为 `int` 应进行**符号扩展**；只有 `unsigned char` 才进行零扩展。

```c
int main()
{
    // 例子1: 高位 -> 低位
    int x = 165537, u = -34991; // int4B=32位
    // x,y,u,v十六进制表示为 0x000286A1 0x86A1 0xFFFF7751 0x7751
    short y = (short)x, v = (short)u;
    //输出 x=165537, y=-31071 | x=0x000286A1; y=0x86A1
    printf("x=%d, y=%d\n", x, y);
    //输出 u=-34991, v=30545 | u=0xFFFF7751; v=0x7751
    printf("u=%d, v=%d\n", u, v);

    // 例子2: 低位 -> 高位
    short x1 = -4321;
    int y1 = x1;
    unsigned short u1 = (unsigned short)x1;
    unsigned int v1 = u1;
    // x1,y1,u1,v1十六进制表示为 0xEF1F 0xFFFFEF1F 0xEF1F 0x0000EF1F
    // 输出 x1=-4321, y1=-4321 | x1=0xEF1F; y1=0xFFFFEF1F
    printf("x1=%d, y1=%d\n", x1, y1);
    // 输出 u1=61215, v1=61215 | u1=0xEF1F; v1=0x0000EF1F
    printf("u1=%u, v1=%u\n", u1, v1);
    return 0;
}
```

# 二、 运算方法和运算电路

## 2.1. 基本运算部件

**运算器** 由算术逻辑单元（ALU)、移位器、状态寄存器（PSW）和通用寄存器组等组成。  
运算器的基本功能包含四则运算、逻辑运算、移位和求补等操作。**ALU 的核心部件是加法器**。

### 2.1.1. 加法器

#408/组成原理/运算部件/加法器

#### （一） 半加器与全加器

**半加器（Half Adder，HA）：**

- **输入**：两个1位二进制数 $A$ 和 $B$
- **输出**：本位和 $S$，进位 $C_{out}$
- **逻辑表达式**：$S = A \oplus B$，$C_{out} = A \& B$
- **特点**：只能计算两个1位二进制数的和，不能处理来自低位的进位。

**一位全加器（Full Adder，FA）：** - *由两个半加器组合而成*

- **输入**：两个1位二进制数 $A$、$B$，以及来自低位的进位 $C_{in}$->**三输入**
- **输出**：本位和 $S$，进位 $C_{out}$ -> **两输出**
- **逻辑表达式**：和 -> $S = A \oplus B \oplus C_{in}$，进位 -> $C_{out} = (A \& B) | (C_{in} \& (A \oplus B))$
- **特点**：能够处理低位进位，是构成多位加法器的 **基本单元**。
![397](image/2-数据的表示和运算%20-%20计算机组成原理/一位全加器.png)

#### （二） 串行进位加法器（行波进位加法器，RCA）（\*）

将 $n$ 个全加器相连可得到 $n$ 位加法器，称为 **串行进位加法器**，也称 **行波进位加法器**。

- **结构**：多个全加器串联，低位进位输出 $C_i$ 直接作为高位的进位输入 $C_{i+1}$ 。
- **特点**：
  - **进位信号逐级传递**，运算速度较慢，**延迟与位数 $n$ 成正比**。
  - 第 $i$ 位的运算必须等待第 $i-1$ 位进位产生后才能进行。
- 最长运算时间主要由 **进位信号的传递时间** 决定
![514](image/2-数据的表示和运算%20-%20计算机组成原理/n位串行进位加法器.png)

#### （三） 并行进位加法器（先行进位加法器，CLA）（\*）

引入额外的 **先行进位逻辑**，同时产生所有进位信号，无需等待低位进位逐级传递，从而大幅提升运算速度。
**核心逻辑**：

- **进位产生函数 (Generate)**：$G_i=A_i B_i$ 。当 $A_i$ 和 $B_i$ 均为1时，无论有无进位输入，本位都会向高位产生进位。
- **进位传递函数 (Propagate)**：$P_i = A_i + B_i$ 。当 $A_i$ 和 $B_i$ 中至少有一个为1时，来自低位的进位信号可以传播到高位。
- **进位逻辑表达式**：第 $i$ 位产生的进位为 $C_{i+1} = G_i + P_iC_i$ 。将其展开，即可得到仅由原始输入 $A_i$ 、$B_i$ 和最低进位 $C_0$ 表示的 $C_1$、$C_2$ ……，从而让所有进位**同时产生**。
采用**并行进位的目的**是：提高加法器运算速度。
通常采用**两级或多级先行进位加法器**。
![456](image/2-数据的表示和运算%20-%20计算机组成原理/四位全先行进位加法器.png)

#### （四） 带标志加法器

#408/组成原理/标志位

给原加法器增加额外的逻辑电路，用于生成 **标志位 (Flag)**。这些标志位反映了运算结果的特定状态，是 CPU 进行条件判断和分支跳转的基础。
为了加快加法运算的速度，**实际电路一定使用多级先行进位方式**。
**标志位及其生成逻辑**（假设ALU输入为：$A$、$B$，输出为 $F$，最高位进位为 $C_{out}$，次高位进位为 $C_{n-1}$）：

- **OF (Overflow Flag，溢出标志)**：用于有符号整数运算。`OF=1`溢出，`OF=0`未溢出。生成逻辑：$OF = C_{out} \oplus C_{n-1}$。
- **SF (Sign Flag，符号标志)**：表示结果的符号。对于有符号数，直接等于结果的最高位。`SF=1`为负，`SF=0`为正。生成逻辑：$SF = F_{n-1}$。
- **ZF (Zero Flag，零标志)**：当运算结果的所有位均为`0`时置`1`。`ZF=1`结果为 `0`，`ZF=0`结果非 `0`。生成逻辑：$ZF = \overline{F_{n-1} + F_{n-2} + ... + F_0}$。
- **CF (Carry Flag，进位/借位标志)**：用于无符号整数运算。加法时表示进位，减法时表示借位。`CF=1`表示溢出，`CF=0`表示未溢出。生成逻辑：$CF = C_{out}$。

#### （五） 算术逻辑部件（ALU）

#408/组成原理/ALU

**算术逻辑部件 (Arithmetic Logic Unit, ALU)** 是CPU的核心部件之一，负责执行所有 **算术运算** 和 **逻辑运算**，以及 **移位操作**。

- **算术运算**：加法、减法、自增、自减等。
- **逻辑运算**：与（AND）、或（OR）、非（NOT）、异或（XOR）等。
- **移位运算**：逻辑左移、逻辑右移、算术右移、循环移位等。

**ALU 基本组成**：ALU的核心是一个**带标志加法器**，并辅以移位器、逻辑运算单元和标志位生成电路。

**ALUop**：是操作控制端，通过接收**操作码 (op)** 控制信号，选择对输入的操作数执行相应的运算。其位数决定了操作种类，位数为 `3` 时，有 $2^3=8$ 种操作。在ALUop 的控制下，由一个多路选择器 `MUX` 选择输出某种操作结果。

**MUX**：是多路选择开关，它从多个信号中选择一个送到输出端。

## 2.2. 加/减运算

#408/组成原理/二进制运算/2-移位运算

### 2.2.1. 移位运算

一般来说。**逻辑移位->无符号整数；算术移位->有符号整数（补码形式）**。

#### （一） 逻辑移位

**逻辑移位** 将操作数视为 **无符号整数**，移位时 **不考虑符号位**，空出的位统一补 `0`。

| **移位类型** |     **操作规则**     | **示例（8位->移1位）**   |
| ------------ |:--------------------:|:------------------------ |
| **逻辑左移** | 高位丢弃，低位补 `0` | `1001 0110`->`0010 1100` |
| **逻辑右移** | 低位丢弃，高位补 `0` | `1001 0110`->`0100 1011` |
**特点**：

- 适用于 **无符号整数** 的移位操作；
- 逻辑左移一位相当于乘以 `2`（若无溢出）；
- 逻辑右移一位相当于除以 `2`（向下取整）；

> **注意事项**：逻辑移位 **不保留符号位**，是整体移动，不适用于有符号数的移位运算。

#### （二） 算术移位

**算术移位** 将操作数视为有 **符号整数（补码表示）**，移位时 **保持符号位不变**，并根据符号位填充空位。

| **移位类型** | **操作规则**           | **示例（8位补码）**                 | **真值** |
| :------: | :----------------- | :--------------------------- | ------ |
| **算术左移** | 高位丢弃（含符号位），低位补 `0` | `1111 1000`（-8）->`1111 0000` | -16    |
| **算术右移** | 低位丢弃，高位补**符号位**    | `1111 1000`（-8）->`1111 1100` | -4     |

> **对于补码真值计算：**

 1. 可以采用最高位的次数与其他位次数对应的值相加。比如：$11111000 = (-2^7)+（2^6 + 2^5 + 2^4 + 2^3) = -8$
 2. 从负数最大(`1,···0···0`->`-2^(n-1)`)和最小(`1,···1···1`->`-1`)逆推。比如：11111000与-1: 11111111 相差 00000111，即差7，而前者明显大于后者，因此结果值是-1-8=-8

**特点**：

- 算术左移一位相当于乘以 `2`，算术右移一位相当于除以 `2`（向零取整）；
- 移位前后符号位保持不变。

> **注意事项**：
>
> 1. 算术左移时，若移出的高位与新的符号位不同，则发生 **溢出**；
> 2. 正数算术右移高位补 `0`，负数算术右移高位补 `1`。

### 2.2.2. 补码加/减运算

#408/组成原理/二进制运算/3-补码运算/补码加减运算

#### （一） 加减运算

补码加减运算规则简单，易于硬件实现。设字长为`n+1`，运算公式如下：

- **加法**：$[X + Y]_补 = ([X]_补 + [Y]_补) \ mod \ 2^{n + 1}$
- **减法**：$[X - Y]_补 = ([X]_补 + [-Y]_补) \ mod \ 2^{n + 1}$

**补码计算特点：**

1. 按二进制加法规则运算，**逢二进一**；
2. 加法则两数补码相加；减法则将被减数与减数的负数补码相加；
3. 符号位与数值位一同参与运算，结果的符号位由运算自然得出；
4. 运算结果 **自动截断** 为`n+1`位（模 $2^{n+1}$)，**高位进位被丢弃**，**结果仍为补码** 形式。

>例：设字长 8 位（含 1 位符号位），A=15, B=24，求 $[A+B]_补$ 和 $[A-B]_补$。
>
>1. 先写出其原码：$A=0000\ 1111$; $B=0001\ 1000$  
>2. 写出对应的补码形式：$[A]_补=0000\ 1111$; $[B]_补=0001\ 1000$; $[-B]_补=1110\ 1000$
>3. 那么结果相加即可，$[A+B]_ 补=0011\ 0111$; $[A-B]_补 = [A]_补 + [-B]_补 = 1111 \ 0111$
>4. 对应真值分别是 `+39`; `-9`

#### （二） 溢出判别

补码加减运算仅再 **同号相加** 或 **异号相减** 时可能发生溢出。常用以下三种方法

1. **采用一位符号位**：

- 规则：两个正数相加得负数，或两个负数相加得正数，则溢出。
- 逻辑表达式：$V = (X_s Y_s \overline{S_s}) + (\overline{X_s}\ \overline{Y_s} S_s)$ 其中 $X_s$、$Y_s$ 为加数符号，$S_s$ 为结果符号。

2. **采用一位符号位并结合进位情况**：

- 规则：符号位进位 $C_s$ 与最高数值位进位 $C_{max}$ 不同时发生溢出。
- 逻辑表达式：$V = C_s \oplus C_{max}$ 这是硬件最常用的方法。
- 例：8位补码 `1000 0000 + 1000 0000`，符号位进位 $C_s = 1$，最高数值位进位 $C_{max} = 0$，异或得 `1`，溢出；结果为 `0000 0000`，两个负数相加得 `0`，明显错误。

3. **采用双符号位（变形补码）**：

- 规则：用两个符号位（`00` 正，`11` 负），运算后双符号位为 `01` 表示正溢出，`10` 表示负溢出。
- 例：`01 11111`（正溢）表示结果$> 2^{n-1}-1$；`10 00000`（负溢）表示结果 $< -2^{n-1}$。
- 特点：溢出判断简单，但需多占用一位存储。
**注意**：无符号数加法判断进位 $C_s$，有符号数判断溢出 $V$；减法可通过 $[-Y]_补$ 转换为加法，再按上述规则判断。

**特点**：**符号位与数值为分别处理**，符号位不参与运算，*同号为正，异号为负*。

2. 乘积的**数值位**：两个乘数绝对值的乘积。

### 2.3.2. 除法（\* 过程非重点）

**除法运算由累加和左移（逻辑左移）实现。**

#### （一） 原码除法运算【不恢复余数法】
**特点**：**商符**和**商值**分开进行。商符由两个操作数的符号位**异或**得到。

**手算规则**：通过比较余数和除数的大小确定商值。
- 若够减（差为正），上商 `1`。
- 若不够减（差为负），上商 `0`。
![390](image/2-数据的表示和运算%20-%20计算机组成原理/原码除法手算.png)

**符号扩展规则**：

| 类型         | 扩展方式                     | 示例（16位→32位）        |
|:------------ |:---------------------------- |:------------------------ |
| 正数         | 高位补 `0`                   | `0x8FA0` → `0x0000 8FA0` |
| 负数（原码） | 符号位不变，数值位与正数相同 | 同上                     |
>**注意**：除数不断右移后，其位数可能超过 ALU 位数。
![390](image/2-数据的表示和运算%20-%20计算机组成原理/除法逻辑结构图.png)

#### （二） 补码除法运算【加减交替法】

**特点**：**符号位与数值位一起参加运算，商符自然形成**，无需单独计算。
**公式**：`A(被除数) ÷ B(除数) = C(商) …… D(余数)`
**上商规则**：

| 余数与除数符号 | 上商 | 操作 |
| :--- | :--- | :--- |
| 同号 | `1` | 余数左移后减去除数 |
| 异号 | `0` | 余数左移后加上除数 |
> **注意**：最后一步商强制置 `1`。

# 三、 浮点数的表示和运算
#408/组成原理/二进制运算/4-浮点数运算

## 3.1. 浮点数的表示

二进制表示小数会出现问题，如不能用二进制表示 `0.1`，所以设计了浮点数来表示小数。

在位数有限的情况下，既**扩大了数的表示范围**，又**保持了数的有效精度**。
$$真值 = 尾数 \times 2^{阶码}$$ 
尾数指具体的**小数**，其有两种表示形式：**机器数形式**以及**真值形式**，不同的上下文所描绘的尾数指表示形式上的不同。
> **注意**：
>   浮点数的表示不唯一。
>   数的符号以尾数符号为准。

![](image/2-数据的表示和运算%20-%20计算机组成原理/浮点数表示.png)

### 3.1.1. 浮点数的表示范围

![394](image/2-数据的表示和运算%20-%20计算机组成原理/浮点数表示范围.png)

**上溢**：数据一旦产生 **上溢**，计算机必须**中断运算**操作，进行溢出处理。
- **正上溢**：运算结果大于最大正数；
- **负上溢**：小于绝对值最大负数。
**下溢**：数据 **下溢时，浮点数值趋于零**，计算机将其当作机器零处理。
- **正下溢**：运算结果在 `0` 至最小正数之间；
- **负上溢**：运算结果在 `0` 至绝对值最小负数之间。
> **注意**：上溢阶符为正；下溢阶符为负。

### 3.1.2. 浮点数的规格化

**规格化**：规定尾数的最高数位必须是一个**有效值**（即 `1`）。
**目的**：增加数据的**表示精度**，避免有效数字丢失。
> **示例**：`0.0110B` 按权展开为 $0 \times 2^{-1} + 1 \times 2^{-2} + 1 \times 2^{-3} + 0 \times 2^{-4}$，最高位为 `0` 不是有效值，需左规。

| 类型     | 触发条件                        | 操作         | 阶码变化        | 示例                            |
| :----- | :-------------------------- | :--------- | :---------- | :---------------------------- |
| **左规** | 尾数最高位为 `0`（如 `0.0...01xxx`） | 尾数**左移**一位 | 阶码**减 `1`** | $0.0011×2^5$ -> $1.1×2^2$     |
| **右规** | 尾数溢出（如 `1x.xxx` 或 `10.xxx`） | 尾数**右移**一位 | 阶码**加 `1`** | $10.011×2^5$ -> $1.0011×2^6$  |
> **注意**：
>   左规可能需多次进行，直到尾数最高位为 `1`；右规只需一次。
>   右规前，阶码已经达到最大值，则右规后溢出。

### 3.1.3. 规格化后的尾数表示范围

**原码规格化**：
- 正数形式：`0.1xxx...x`，范围 $1/2 \leq M \leq (1-2^{-n})$ 
- 负数形式：`1.1xxx...x`，范围 $-(1-2^{-n}) \leq M \leq -1/2$ 
**补码规格化**：
- 正数形式：`0.1xxx...x`，范围 $1/2 \leq M \leq (1-2^{-n})$ 
- 负数形式：`1.0xxx...x`，范围 $-1 \leq M \leq -(1/2+2^{-n})$ 
> **注意**：补码规格化负数的最高位为 `1.0...`，其表示范围比原码更宽（可到 `-1`）。

## 3.2. 浮点数的加/减运算
**（选择题直接用数学知识计算）**

| 步骤       | 操作      | 说明                                      |
| :------- | :------ | :-------------------------------------- |
| **对阶**   | 小阶向大阶看齐 | 阶码增大，尾数右移。目的：使两个操作数的小数点位置对齐             |
| **尾数求和** | 尾数相加减   | 对阶后的尾数直接进行加减运算                          |
| **规格化**  | 左规 / 右规 | 将结果调整为规格化形式（尾数最高位为 `1`）                 |
| **舍入**   | 尾数舍入    | 对阶或右规时可能发生。舍入不一定产生误差（若移出的低位全为 `0` 则无误差） |
| **溢出判断** | 检查阶码    | 若阶码双符号位为 `01` 或 `10`，则发生溢出              |
> **注意**：舍入是浮点数特有概念，定点数无舍入。

## 3.3. IEEE 754 标准
**IEEE 754 中尾数用原码表示，阶码用移码表示。**

### 3.3.1. 浮点数格式

| 精度 | 符号位 `S` | 阶码 `E` | 尾数 `M` | 总位数 | 偏移量 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **单精度（float）** | 1 | 8 | 23 | 32 | 127 |
| **双精度（double）** | 1 | 11 | 52 | 64 | 1023 |
$$N = (-1)^S \times 1.M \times 2^{E - 偏移量}$$  
> **注意**：
>   单精度阶码取值 1~254，偏移值为 **127**。
>   单精度：最小值 -> $1*2^{1-127}$；最大值 -> $(2-2^{23})*2^{256-127}$
>   双精度阶码取值 1~2046，偏移值为 1023。

### 3.3.2. 规格化数与特殊值
| 类型 | 阶码 `E` | 尾数 `M` | 真值 |
| :--- | :--- | :--- | :--- |
| **规格化数** | `1` ~ `254`（单精度） | 任意 | $(-1)^S \times 1.M \times 2^{E-127}$ |
| **非规格化数** | `0` | $\neq 0$ | $(-1)^S \times 0.M \times 2^{-126}$ |
| **零** | `0` | `0` | `0` |
| **无穷大** | `255`（全1） | `0` | $\pm \infty$ |
