# 一、 计算机网络基本概念

## 1.1. 计算机网络的定义与组成

### 1.1.1. 定义

- **计算机网络**：是一个将分散的、具有独立功能的计算机系统；通过通信设备与线路连接起来，由功能完善的软件实现资源共享和信息传递的系统。
- **简记**：计算机网络是 **互连的、自治的** 计算机集合
	- **互连**：互联互通；
	- **自治**：无主从关系，即相互连通，但不能彼此控制。

### 1.1.2. 功能

- 数据通信(**最基本的功能**)；
- 资源共享：包括信息共享、软件共享、硬件共享；
- 分布式管理：多台计算机各自承担同一工作的不同部分；
- 提高可靠性；
- 负载均衡。

> **注意**：网络资源 = 硬件资源 + 软件资源 + 数据资源

### 1.1.3. 组成

#### （一） 按组成部分
**计算机网络 = 硬件 + 软件 + 协议**

**硬件**：主机，通信链路(*双绞线，光纤*)，交换设备(*路由器、交换机*)，通信处理机(*网卡*)。
**软件**：网络操作系统，邮件收发程序，FTP程序，聊天程序。

#### （二） 按功能
**计算机网络 = 通信子网 + 资源子网**

**资源子网**：实现资源共享功能的设备和软件集合(*计算机软件*)。
**通信子网**：各种传输介质、通信设备、相应的网络协议组成(*网桥、交换机、路由器*)。

#### （三） 按工作方式
**计算机网络 = 边缘部分 + 核心部分**

**边缘部分**：由所有连接在互联网上的 **主机** 组成。这部分是用户直接使用的，用来通信(*传送数据、音频或视频*)和资源共享。
**核心部分**：由大量网络和连接这些网络的 **路由器** 组成。这部分是为边缘部分提供服务的(*提供连通性和交换*)。

## 1.2. 计算机网络的分类

### 1.2.1. 按分布范围

- **广域网(*WAN，Wide Area Network*)**：
	- 采用交换技术；
	- 区分广域网局域网，取决于采用的协议。
- **局域网(*LAN，Local Area Network*)**：
	- 采用广播技术；
	- 局域网通过路由器接入广域网。
- 城域网(*MAN，MetroPolitan Area Network*)。
- 个人区域网(*PAN，Personal Area Network*)。

### 1.2.2. 按交换技术分类

[物理层中的交换技术](<2-物理层 - 计算机网络.md## 2.3. 交换方式>)

- 电路交换：
	- 缺点：线路复用率低，不便于进行差错控制；
	- 优点：数据直接传送，时延小。
- **报文交换**：
	- **缺点**：附加信息开销大；
	- **优点**：解决了电路交换的缺点。
- **分组交换(*主流网络使用的交换技术*)**：
	- **缺点**：附加信息开销大；
	- **优点**：缓冲易于管理，更适合应用。

![555](image/1-计算机网络体系结构%20-%20计算机网络/交换方式比较.png)

### 1.2.3. 按拓扑结构分类
(**指通信子网的拓扑结构**)

- 总线形网络；
- 星形网络；
- 环形网络；
- 网状网络(*多用于广域网*)。

![555](image/1-计算机网络体系结构%20-%20计算机网络/网络拓扑结构.png)

### 1.2.4. 按使用者分类

- 公用网(*public network*)；
- 专用网(*private network*)。

### 1.2.5. 按传输技术分类

- 广播式网络；
- 点对点网络。

> **注意**：广播式网络可以不要网络层，可以不存在路由选择问题，但是需要服务访问点。

### 1.2.6. 按传输介质分类

- **有线网络**：双绞线网络，同轴电缆网络；
- **无线网络**：蓝牙、微波、无线电。

## 1.3. 计算机网络的主要性能指标 ※※

### 1.3.1. 速率

速率 = 数据率 = 数据传输率 = 比特率

**单位**：`b/s`，`kb/s`，`Mb/s`，`Gb/s`，`Tb/s`

> **注意**：基本的单位换算，$10^3$倍。
> [存储容量](<3-存储器层次结构 - 计算机组成原理.md### 2.1.1. 存储容量>) 1Byte(*字节*) = 8bit(*比特*)

### 1.3.2. 带宽

带宽：**某个信号具有的频带宽度**(*单位：Hz*)
带宽 = 表示网络的通信线路传输数据的能力 = 单位时间内从网络中某信道所能通过的 *最高数据率*(*单位：bit/s*)

速率与带宽都是速度单位，这里速率是 *实际的传输速率*，而带宽是 **理想状态下** 的最大传输速率。

### 1.3.3. 吞吐量

吞吐量：**在单位时间通过某个网络(*或信道、接口*)的数据量**(*单位：b/s，kb/s*)
吞吐量受*网络的带宽*或*网络的额定速率*的限制。

### 1.3.4. 时延(延迟)

**时延/延迟**：指数据(*报文/分组/比特流*)从网络(*或链路*)的一端传送到另一端所需的时间。
**总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延**

- **发送/传输时延** = 从发送分组的第一个比特算起，到该分组最后一个比特发送完毕所需的时间 = **数据长度 / 发送速率**；
- **传播时延** = 电磁波在信道中传输一定距离而花费的时间。取决于电磁波的传输速率和信道(*链路*)的长度 = **信道长度 / 电磁波在信道上传播的速率**；
- **处理时延** = 主机或路由器在收到分组时要花费一定的时间进行处理。
- **排队时延**：节点缓存队列中分组排队所经历的时间。

#### （一） 时延的三种经典场景

![400](image/1-计算机网络体系结构%20-%20计算机网络/分组交换网示例.png)

以分组交换网为例，网络包含两段链路，最大传输速率如图中所示。假设主机A向主机B发送一个长度为 1000B 的分组：
情况1：(*忽略传播时延、处理时延和排队时延*)
	[A->链路1] 的分组发送时延 = 1000B ÷ 100Mb/s = 0.08ms；
	[路由器->链路2] 的分组发送时延 = 1000B ÷ 80Mb/s = 0.1ms；
	总时延 = 0.08 + 0.1 ms = 0.18 ms。
 
情况2：(*考虑传播时延，假设链路1和链路2传播时延分别是0.01ms和0.05ms*)
	总时延 = 0.01 + 0.08 + 0.05 + 0.1 ms = 0.24 ms。

情况3：(*还考虑路由器的处理时延和排队时延，假设这两项时延合计0.04ms*)
	总时延 = 0.01 + 0.08 + 0.04 + 0.05 + 0.1 ms = 0.28 ms。

![555](image/1-计算机网络体系结构%20-%20计算机网络/时延分析示例.png)

> **注意**：通常无需考虑 *处理时延和排队时延*，若另有说明则考虑。

### 1.3.5. 时延带宽积

时延带宽积 = **传播时延 x 带宽**
时延带宽积表示的是 **容量**。

![300](image/1-计算机网络体系结构%20-%20计算机网络/时延带宽积示例.png)

### 1.3.6. 往返时延(RTT)

RTT = 往返传播时延 + 末端处理时间
从发送端发送数据开始，到发送方收到接收方的确认(*接收方收到数据后立即发送确认*)共经历的时延。

![400](image/1-计算机网络体系结构%20-%20计算机网络/往返时延RTT.png)

### 1.3.7. 利用率

信道利用率 = **有数据通过时间 / (无+有) 数据通过时间**
网络利用率 = **全网络的信道利用率加权平均值**

> **注意**： 利用率不是越高越好，时延会随着利用率的增加而增加。

# 二、 计算机网络体系结构

**计算机网络体系结构的形成**：
- 相互通信的两个计算机系统必须高度协调工作才行，而这种协调是相当复杂的；
- 分层可以将庞大而复杂的问题转化为若干较小的局部问题，而这些较小的局部问题就比较易于研究和处理。

**实体**：表示任何可以发送或接受信息的硬件或软件进程。同一层的实体称为对等实体。

**数据组成**：
- **SDU服务数据单元**：为完成用户所要求的功能而应传送到的数据；
- **PCI协议控制信息**：控制协议操作的信息；
- **PDU协议数据单元**：对等层次之间传送的数据单位；
- 每一层的PDU会作为下一层的SDU，然后和PCI组成该层的PDU，再作为下下层的SDU……直到物理层。

![555](image/1-计算机网络体系结构%20-%20计算机网络/网络各层数据单元之间的关系.png)

## 2.1. 分层结构的基本概念

### 2.1.1. 分层基本原则

![555](image/1-计算机网络体系结构%20-%20计算机网络/协议-接口-服务三者关系.png)

**协议**：
- 简称协议，是为了进行网络中的数据交换而建立的规则、标准或约定；
- 协议是 **水平的**，即协议是控制对等实体之间的通信的规则；
- **协议三要素**：
	- **语法**：规定传输数据的格式；
	- **语义**：规定所要完成的功能；
	- **同步(*时序*)**：规定各种操作的顺序。

**接口(*访问服务点 SAP*)**：
- 同一个系统中相邻两层的实体进行交互(*即：交换信息*)的地方；
- 仅仅在相邻两层间有接口，且所提供服务的具体实现细节对上一层完全屏蔽。

**服务**：
- **下层为相邻上层** 提供的功能调用；
- 服务是 **垂直的**，即服务是由下层向上层通过层间接口提供的。

| 概念     | 定义          | 特点                |
| :----- | :---------- | :---------------- |
| **协议** | 对等实体之间通信的规则 | **水平方向**(*同层之间*)  |
| **接口** | 相邻层之间的服务访问点 | **垂直方向**(*上下层之间*) |
| **服务** | 下层向上层提供的功能  | **垂直方向**          |

- 各层之间 **相互独立**，每层只实现一种相对独立的功能；
- 每层之间界面自然清晰，易于理解，**相互交流尽可能少**；
- **结构上可分割开**。每层都采用最合适的技术来实现；
- 保持 **下层对上层的独立性**，上层 **单向** 使用下层提供的服务；
- 能促进标准化工作。

### 2.1.2. 各层的功能

**分段和重装**：发送端将要发送的数据块 **划分** 为更小的单位，在接收端再进行 **还原**；
**复用和分用**：发送端几个高层会话 **复用** 一条低层的连接，在接收端再进行 **分用**；
**连接建立和释放**：交换数据前先 **建立一条逻辑连接**，数据传送结束后 **释放连接**。

## 2.2. 网络模型

#### （一） OSI七层模型

![555](image/1-计算机网络体系结构%20-%20计算机网络/OSI参考模型.png)

1. **物理层**
	- **任务**：在物理媒体上**透明传输原始比特流**
	- **功能**：规定机械/电气/功能/过程特性；确定比特传输方式(*单工/半双工/全双工*)
	- **PDU**：比特
	- **设备**：中继器、集线器
2. **数据链路层**
	- **任务**：在相邻节点之间**实现可靠的帧传输**
	- **功能**：组帧、差错控制(*CRC/海明码*)、流量控制、介质访问控制(*CSMA/CD等*)
	- **PDU**：帧
	- **设备**：网桥、交换机
3. **网络层**
	- **任务**：**数据包从源到目的地的传输**，完成路由选择与分组转发
	- **功能**：
	  - 路由选择：确定数据包从源到目的地的路径
	  - 分组转发：将数据包从输入端口转移到输出端口
	  - **差错控制**：使对等实体之间的**通信更加可靠**
	  - **流量控制**：发送端的发送速率必须使接收端**来得及接受、不要太快**
	  - **拥塞控制**：拥塞状态 = 结点**来不及接受分组而要丢弃大量分组**的情况，网络层要采取一定措施缓解这种阻塞
	- **PDU**：分组/数据报
	- **设备**：路由器
4. **传输层**
	- **任务**：提供 **端到端(*进程到进程*)** 的可靠通信
	- **功能**：
	  - 端到端连接管理(*建立/维护/释放*)
	  - 分段与重组(*应用层数据分段，接收端重组*)
	  - 可靠传输(*确认、重传、序号管理*) —— TCP
	  - 无连接传输 —— UDP
	  - 流量控制与拥塞控制
	- **PDU**：报文段/数据段
	- **协议**：TCP、UDP
5. **会话层**
	- **任务**：**建立、管理和终止**不同主机上进程之间的会话连接
	- **功能**：
	  - 会话的建立、维护和释放
	  - 提供**同步点(*同步标记*)**，便于从断点恢复
	  - 管理用户登录、注销等
	- **PDU**：报文
6. **表示层**
	- **任务**：**处理数据格式的转换**，使不同系统之间能理解对方的数据
	- **功能**：
	  - 数据压缩与解压缩
	  - 数据加密与解密
	  - 数据格式转换(*如：ASCII/EBCDIC、整数大小端等*)
	- **PDU**：报文
7. **应用层**
	- **任务**：**为用户提供网络应用服务**，是用户与网络的交互接口
	- **功能**：提供用户应用程序访问网络的接口；支持常见的网络应用协议
	- **PDU**：报文
	- **协议**：HTTP、FTP、SMTP、POP3、DNS、DHCP等

#### （二） TCP/IP模型

![](image/1-计算机网络体系结构%20-%20计算机网络/TCPIP模型层次结构.png)

**TCP/IP四层结构(从下到上)**：

| 层次  | 名称    | 主要协议                   | 与OSI对应关系 |
| :-- | :---- | :--------------------- | :------- |
| 4   | **应用层**   | HTTP、FTP、SMTP、DNS、DHCP | OSI 5~7层 |
| 3   | **传输层**   | TCP、UDP                | OSI 第4层  |
| 2   | **网际层**   | IP、ICMP、ARP            | OSI 第3层  |
| 1   | **网络接口层** | Ethernet、WiFi、PPP      | OSI 1~2层 |

> **注意**：TCP/IP模型中，**网络接口层**不是一种具体的协议，而是一个接口层，用于适配各种底层网络技术。

#### （三） 五层协议结构

| 五层协议的体系结构 |
| --------- |
| 应用层       |
| 运输层       |
| 网络层       |
| 数据链路层     |
| 物理层       |

1. **应用层**：通过应用进程间的交互来完成特定网络应用。数据单位：*报文*；
2. **运输层**：为进程提供通用数据传输服务。主要用以下两个协议：
	1. **TCP**：传输控制协议。提供面向连接、可靠的传输服务。数据单位：*报文段*；
	2. **UDP**：用户数据报协议。提供无连接、尽最大努力的传输服务。数据单位：*用户数据报*；
	3. **TCP 主要提供完整性服务**；**UDP 主要提供及时性服务**。
3. **网络层**：
	1. 为主机提供数据传输服务。把传输层传递下来的报文段或者用户数据报**封装**成分组；
	2. 最重要的协议是 IP(*网际协议，Internet Protocal*)。
4. **数据链路层**：为同一链路的主机提供数据传输服务。把网络层传下来的分组封装成帧。
5. **物理层**：主要负责在物理线路上传输原始数据的二进制数据。

> **注意**：五层体系结构只是将网络TCP的*网络接口层*拆分成*数据链路层*和*物理层*，即保留OSI体系的1，2层内容。
> 在现实应用中仍然使用TCP/IP体系，五层协议的体系便于细致理解结构。

![555](image/1-计算机网络体系结构%20-%20计算机网络/三种模型的对比.png)

#### （四） TCP/IP与OSI的关键区别

![555](image/1-计算机网络体系结构%20-%20计算机网络/TCPIP与OSI参考模型的层次对应关系.png)

|       | OSI模型                  | TCP/IP模型             |
| ----- | ---------------------- | -------------------- |
| **传输层服务** | 面向连接                   | 面向连接/无连接             |
| **网络层服务** | 面向连接/无连接               | 无连接                  |
| **分层情况**  | 分成七层                   | 分成四层                 |
| **设计理念**  | 自上而下，首先设计理想化的模型，然后尝试使用 | 自下而上，从实际的技术应用出发进行设计。 |

- OSI是**先有模型后有协议**；TCP/IP是**先有协议后有模型**；
- OSI的网络层支持无连接和面向连接两种服务；TCP/IP的网际层**只提供无连接服务**；
- TCP/IP的应用层合并了OSI的会话层、表示层和应用层。
