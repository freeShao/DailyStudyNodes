## 1.1. 星级评分核心逻辑说明

### 1.1.1. 五星（⭐⭐⭐⭐⭐）—— 必拿分考点，必须烂熟于心

这些是每年必考、分值最高的核心内容，通常占计网总分值的60%以上：

| 考点 | 考查频率 | 典型题型 |
| :--- | :--- | :--- |
| OSI与TCP/IP体系结构对比 | 每年 | 选择题 |
| 奈奎斯特定理与香农定理 | 每年 | 选择题（计算） |
| GBN与SR协议 | 高频 | 选择题+综合题 |
| CSMA/CD协议（最小帧长/退避算法） | 每年 | 选择题 |
| 子网划分与CIDR | 每年 | 选择题+综合题 |
| TCP拥塞控制（慢启动/拥塞避免/快重传） | 每年 | 选择题+综合题 |
| TCP连接管理（三次握手/四次挥手） | 高频 | 选择题+综合题 |
| IPv4分组分片与重组 | 高频 | 选择题 |

### 1.1.2. 四星（⭐⭐⭐⭐）—— 高分保障，需熟练

这些是次高频考点，掌握后能显著拉开分数差距：

| 考点 | 考查频率 | 说明 |
| :--- | :--- | :--- |
| 时延与时延带宽积计算 | 每年 | 第一章最重要计算 |
| 滑动窗口机制 | 高频 | 流量控制基础 |
| ARP协议解析流程 | 高频 | 选择题常考 |
| NAT原理 | 高频 | 网络地址转换 |
| 路由表与最长前缀匹配 | 高频 | 转发过程 |
| 端口号与熟知名（21/23/25/53/80） | 每年 | 必背 |
| DNS解析（递归/迭代） | 高频 | 选择题常考 |
| FTP控制连接与数据连接 | 高频 | 选择题常考 |

### 1.1.3. 三星（⭐⭐⭐）—— 基础得分，理解即可

这些是基础概念，选择题常考，理解原理即可：

| 考点 | 说明 |
| :--- | :--- |
| 三种交换方式（电路/报文/分组） | 对比表格记忆 |
| CRC差错检测 | 模2除法能算即可 |
| VLAN基本原理 | 802.1Q帧格式 |
| IPv6主要特点 | 地址128位、与IPv4的区别 |
| RIP/OSPF/BGP对比 | 协议对比表 |
| HTTP协议 | 请求/响应格式 |
