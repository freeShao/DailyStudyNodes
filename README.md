# DailyStudyNotes - 日常学习笔记记录

## 1. 学习笔记记录

### 1.1. 技术学习笔记

#### （一） UbuntuSettings

此文档详细介绍了在 Windows 上通过 WSL2 安装 Ubuntu 22.04 的完整流程，包括：启用虚拟化功能、导出与导入 Ubuntu 系统至 D 盘、创建新用户及配置 sudo 权限、以及可选的 systemd 守护进程安装配置。

#### （二） GitSetting

此文档记录了在 Ubuntu 22.04 上安装 Git 的步骤，包括：更换清华镜像源、配置用户信息、以及通过 SSH 密钥实现与 GitHub 的安全连接配置。

#### （三） Conda

此文档介绍了在 Ubuntu 22.04 上安装 MiniConda 的流程，包括：下载安装脚本、执行安装与环境变量配置、以及可选的 Conda 镜像源配置（清华源/中科大源），并附常用命令速查表。

#### （四） Docker

此文档详细记录了在 Ubuntu 22.04 上安装 Docker 的完整步骤，包括：卸载旧版本、安装依赖、添加 GPG 密钥与仓库、安装 Docker、配置命令补全工具、配置 Docker 镜像加速器、以及常用命令速查表。

#### （五） HadoopSetting

此文档介绍了在 Ubuntu 22.04 上搭建 Hadoop 集群的完整流程，包括：安装 Java 8、配置 SSH 免密登录、下载安装 Hadoop 3.3.6、配置环境变量与各项 XML 文件、格式化 NameNode、启动集群、以及验证集群功能。同时记录了安装 Spark 3.5.8 的配置方法。

#### （六） HadoopProjectNote

此文档记录了基于 Hadoop 集群的人口普查数据分析项目实践，包括：数据来源说明（中国国家统计局）、实验环境配置、数据上传至 HDFS、以及基本的数据处理流程。

### 1.2. 期末学科复习笔记

#### （一） 单片机复习源文件

#### （二） 复变函数复习源文件

此目录包含复变函数课程的复习测试题资料。

#### （三） 大数据复习源文件

此目录收录了大数据课程（智慧树平台）的考试复习资料，包含智慧树原题与大题汇总，涵盖题型划分及题库占比分析。

#### （四） 射频复习源文件

此文档整理了《无线射频识别技术与应用》课程的期末考试大纲，涵盖 RFID 系统标签分类、工作原理、编码与调制方式、防冲突机制等核心知识点。
